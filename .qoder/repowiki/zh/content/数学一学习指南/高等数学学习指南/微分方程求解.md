## 详细组件分析

### 一阶微分方程（识别与解法）
- 可分离变量：将 dy/dx = g(x)h(y) 化为 dy/h(y) = g(x)dx 后积分得通解
- 齐次方程：令 u = y/x，转化为关于 u 的可分离变量方程
- 一阶线性：标准形 y' + P(x)y = Q(x)，使用积分因子或常数变易法得到通解公式
- 伯努利方程：通过 z = y^{1-n} 转化为一阶线性
- 全微分方程：满足恰当条件时，求原函数 u(x,y)=C

```mermaid
flowchart TD
S(["进入一阶方程"]) --> Sep{"是否可分离变量？"}
Sep --> |是| Int1["分离变量并积分"]
Sep --> |否| Hom{"是否齐次？"}
Hom --> |是| SubU["令 u=y/x，化为一阶可分离"]
Hom --> |否| Lin{"是否线性？"}
Lin --> |是| IF["用积分因子或常数变易法"]
Lin --> |否| Bern{"是否伯努利？"}
Bern --> |是| ZSub["z=y^{1-n} 转线性"]
Bern --> |否| Exact{"是否全微分？"}
Exact --> |是| Potential["求原函数 u(x,y)=C"]
Exact --> |否| EndS(["无法归类/需其他方法"])
Int1 --> Out(["写出通解"])
SubU --> Out
IF --> Out
ZSub --> Out
Potential --> Out
```

### 可降阶的高阶方程（缺变量换元）
- 缺 y：令 p = y'，则 y'' = p'，化为一阶方程 p' = f(x,p)
- 缺 x：令 p = y'，则 y'' = p·dp/dy，化为一阶方程 p·dp/dy = f(y,p)
- 关键：明确 p 对谁求导，避免混淆 p' 与 p·dp/dy

```mermaid
sequenceDiagram
participant U as "用户"
participant M as "方法选择"
participant R as "降阶求解"
U->>M : 观察方程是否显含 y 或 x
alt 缺 y
M->>R : 令 p=y', y''=p'
R-->>U : 解一阶 p'=f(x,p)
R-->>U : 再积分 y=∫p dx + C2
else 缺 x
M->>R : 令 p=y', y''=p·dp/dy
R-->>U : 解一阶 p·dp/dy=f(y,p)
R-->>U : 分离变量 ∫dy/p = x + C2
end
```

### 二阶常系数线性微分方程（齐次与非齐次）
- 齐次：y'' + p y' + q y = 0，写特征方程 r^2 + p r + q = 0，根据根的情况写出通解形式
- 非齐次：y'' + p y' + q y = f(x)，通解 = 齐次通解 + 非齐次特解；特解用待定系数法按 f(x) 类型设定形式
- 欧拉方程：x^2 y'' + p x y' + q y = f(x)，令 x = e^t 化为常系数方程

```mermaid
flowchart TD

HomCheck --> |是| Char["写特征方程 r^2+pr+q=0"]
Char --> Roots{"判别根的类型"}
Roots --> RealDistinct["两不等实根 → C1 e^{r1 x} + C2 e^{r2 x}"]
Roots --> Repeated["重根 → (C1 + C2 x) e^{r x}"]
Roots --> Complex["共轭复根 α±βi → e^{α x}(C1 cos βx + C2 sin βx)"]
HomCheck --> |否| NonHom["非齐次：先求齐次通解"]
NonHom --> Particular["按 f(x) 类型设特解形式多项式/指数/三角"]
Particular --> Combine["组合：y = y_h + y_p"]
RealDistinct --> Combine
Repeated --> Combine
Complex --> Combine
Combine --> IC2["代入初始条件定常数"]
IC2 --> Done(["完成"])
```

## 疑难排错指南
- 一阶线性方程：使用前必须化为标准形 y' + P(x)y = Q(x)，确保 y' 系数为 1
- 降阶法：区分缺 y 与缺 x 的不同换元方式，避免混淆 p' 与 p·dp/dy
- 二次积分：降阶后解出 p，还需再积分一次得到 y，注意两个任意常数
- 非齐次特解：根据 f(x) 类型正确设定形式，并注意是否与齐次解重复而需要乘以 x^k
- 初始条件：代入通解后联立方程组求解常数，务必回代验算

## 附录：标准解法速查与应用场景
- 一阶可分离变量：dy/h(y) = g(x)dx → 两边积分
- 一阶齐次：u = y/x → 化为可分离变量
- 一阶线性：y' + P(x)y = Q(x) → 积分因子或常数变易法
- 伯努利：z = y^{1-n} → 转线性
- 全微分：恰当条件成立 → 求原函数 u(x,y)=C
- 可降阶：缺 y 或 x → 换元降阶为一阶
- 二阶常系数齐次：特征方程 r^2 + pr + q = 0 → 依根写通解
- 二阶常系数非齐次：齐次通解 + 待定系数法求特解
- 欧拉方程：x = e^t → 化为常系数

应用场景举例（来自笔记）：
- 几何：切线斜率、法线斜率、曲率关系
- 物理：F = ma、牛顿冷却定律、人口增长模型
