# 第五章——IO管理

## 本章概览

I/O 管理是操作系统五大功能之一，负责管理计算机系统中除 CPU 和内存以外的所有外部设备。本章是 408 统考的重点章节，分值约占 10-15 分，常以选择题和综合题形式出现。核心考点包括 I/O 控制方式、缓冲技术、设备分配和 SPOOLing 技术。

> [!tip] 考情分析
> - 选择题高频考点：I/O 控制方式对比、缓冲时间计算、设备分配数据结构
> - 综合题常考：缓冲时间计算、SPOOLing 工作原理分析
> - 难度系数：中等偏上，需要理解原理并熟练计算

## 考点总结

### 高频考点 TOP 5

1. **四种 I/O 控制方式的对比**（数据传送单位、CPU 干预频率、适用场景）
2. **缓冲时间计算**（单缓冲：max(C,T)+M；双缓冲：max(C,T)）
3. **设备分配数据结构**（DCT、COCT、CHCT、SDT 的作用和关系）
4. **SPOOLing 系统组成**（输入井/输出井/输入缓冲/输出缓冲/输入进程/输出进程/井管理程序）
5. **I/O 软件层次结构**（四层结构的功能划分和职责）

### 易混淆概念

| 概念 A | 概念 B | 区别要点 |
|--------|--------|----------|
| 块设备 | 字符设备 | 信息交换单位不同：块 vs 字符；是否可寻址：是 vs 否 |
| 单缓冲 | 双缓冲 | 处理每块数据时间不同：max(C,T)+M vs max(C,T) |
| DMA 方式 | 通道方式 | DMA 按参数搬一块数据；通道执行程序，可控制多设备 |
| 独占设备 | 共享设备 | 独占设备一次只能被一个进程使用，共享设备可被多个进程交替使用 |
| 机器寄存器 | 外设寄存器 | CPU 芯片内（寄存器名访问）vs 设备控制器内（端口地址访问） |

## 学习建议

> [!note] 学习路径
> 1. 先理解 I/O 设备的分类，建立整体认知
> 2. 重点掌握四种 I/O 控制方式的原理和对比（含 DMA/通道生命周期）
> 3. 通过画图理解 I/O 软件层次结构
> 4. 多做缓冲时间的计算练习
> 5. 结合 SPOOLing 理解虚拟设备的概念

> [!tip] 记忆技巧
> - I/O 控制方式按 CPU 解放程度排序：程序直接控制 < 中断驱动 < DMA < 通道控制
> - 缓冲时间公式：单缓冲记住"加 M"，双缓冲记住"不加 M"
> - 设备分配数据结构：从设备到系统，DCT → COCT → CHCT → SDT

### 学习检测

> [!question] 思考题 1
> 为什么高速设备通常采用 DMA 方式而不是中断驱动方式？

> [!question] 思考题 2
> 双缓冲相比单缓冲，效率提升的原因是什么？

> [!question] 思考题 3
> SPOOLing 技术为什么需要输入井和输出井，直接使用内存缓冲区可以吗？

> [!question] 思考题 4
> 设备分配时为什么要依次检查设备、控制器和通道？
