# IO管理基础（设备分类与I/O接口）


I/O 设备种类繁多，可以从不同角度进行分类。理解设备分类是学习 I/O 管理的基础。

### 按传输速率分类

| 类型 | 速率范围 | 典型设备 | 特点 |
|------|----------|----------|------|
| **低速设备** | 每秒几个字节 ~ 数百字节 | 键盘、鼠标、语音输入设备 | 传输速率低，通常以字符为单位传输 |
| **中速设备** | 每秒数千字节 ~ 数万个字节 | 行式打印机、激光打印机 | 传输速率中等，需要一定缓冲 |
| **高速设备** | 每秒数百千字节 ~ 数兆字节 | 磁盘、光盘、磁带 | 传输速率高，通常以块为单位传输 |

> [!note] 考点提示
> 低速设备通常是字符设备，高速设备通常是块设备，但这不是绝对的，需要具体问题具体分析。

### 按信息交换单位分类

这是操作系统中最常用的分类方式，直接影响设备的管理策略。

| 类型 | 交换单位 | 传输速率 | 寻址方式 | 典型设备 | 可寻址性 |
|------|----------|----------|----------|----------|----------|
| **块设备（Block Device）** | 数据块（通常 512B ~ 4KB） | 高 | 可寻址 | 磁盘、光盘、U盘 | 可随机访问 |
| **字符设备（Character Device）** | 字符（1 字节） | 低 | 不可寻址 | 键盘、鼠标、打印机 | 顺序访问 |

#### 块设备特点

- **可寻址**：可以指定数据块的地址进行读写
- **随机访问**：可以直接访问任意数据块，无需按顺序
- **传输速率高**：适合大批量数据传输
- **通常采用 DMA 方式**：减少 CPU 干预

#### 字符设备特点

- **不可寻址**：无法指定地址，只能顺序读写
- **传输速率低**：逐个字符传输
- **常采用中断驱动方式**：每个字符传输完成后产生中断
- **不需要缓存整个块**：通常只需要单字符缓冲

> [!warning] 重要区别
> 块设备和字符设备的根本区别在于**是否可寻址**和**传输单位**。块设备以数据块为单位，可随机访问；字符设备以字符为单位，只能顺序访问。

### 按共享属性分类

| 类型 | 定义 | 特点 | 典型设备 | 分配方式 |
|------|------|------|----------|----------|
| **独占设备** | 一段时间内只能被一个进程占用 | 安全性高，利用率可能低 | 打印机、磁带机 | 静态分配 |
| **共享设备** | 可被多个进程同时访问 | 利用率高，需要并发控制 | 磁盘、光盘 | 动态分配 |
| **虚拟设备** | 通过虚拟技术将独占设备变为共享设备 | 提高独占设备利用率 | SPOOLing 虚拟打印机 | 虚拟分配 |

#### 独占设备

独占设备在一段时间内只能分配给一个进程使用，直到该进程释放后才能分配给其他进程。

```
进程 A 申请打印机 → 分配成功 → 进程 A 使用 → 进程 A 释放
                                      ↓
                               进程 B 等待
```

> [!tip] 思考
> 为什么打印机是独占设备？如果多个进程同时向打印机输出，打印内容会交错混乱，无法得到正确结果。

#### 共享设备

共享设备可以被多个进程同时访问，通过分时使用提高设备利用率。

```
进程 A 请求磁盘块 1 ──┐
                      ├──→ 磁盘调度 → 依次服务
进程 B 请求磁盘块 2 ──┘
```

#### 虚拟设备

通过 SPOOLing 技术，将一台独占设备虚拟为多台逻辑设备，供多个进程同时使用。

```
进程 A ──→ 输出井 ──┐
                    ├──→ 井管理程序 → 实际打印机
进程 B ──→ 输出井 ──┘
```

> [!important] 核心概念
> 虚拟设备技术的核心思想是**以空间换时间**：用磁盘空间（输入井/输出井）换取设备使用效率的提升。

### 按使用特性分类

| 类型 | 特性 | 典型设备 | 速率特征 |
|:---|:---|:---|:---|
| **人机交互设备** | 人与机器直接交互 | 键盘、鼠标、显示器、打印机 | 通常低速/中速 |
| **存储设备** | 保存程序和数据 | 磁盘、光盘、U盘、磁带 | 通常高速 |
| **网络通信设备** | 计算机之间通信 | 网卡、调制解调器 | 中速~高速 |

> 记忆点：**人机交互=人用、存储=存数据、网络=机器之间用**。

### 四种分类方式的交叉分析

> 四种分类是**互相独立的维度**，任何设备在四个维度上各有一个取值。但典型设备呈现规律性组合：

| 设备 | 交换单位 | 传输速度 | 使用特性 | 共享属性 |
|:---|:---|:---|:---|:---|
| **键盘** | 字符 | 低速 | 人机交互 | 独占 |
| **鼠标** | 字符 | 低速 | 人机交互 | 独占 |
| **显示器** | 字符 | 中速 | 人机交互 | 独占 |
| **打印机** | 字符 | 中速 | 人机交互 | 独占（虚拟化后共享） |
| **磁盘** | 块 | 高速 | 存储 | **共享** |
| **光盘/U盘** | 块 | 高速 | 存储 | 共享 |
| **磁带** | 块 | 中速 | 存储 | 独占 |
| **网卡** | 块（帧） | 高速 | 网络通信 | 共享 |
| **调制解调器** | 字符 | 中速 | 网络通信 | 独占 |

#### 交叉规律（考点）

| 规律 | 内容 |
|:---|:---|
| **规律1** | 人机交互设备 = 字符 + 低速/中速 + 独占（人类输入输出速度慢） |
| **规律2** | 存储设备 = 块 + 高速 + 可共享（磁盘可被多进程同时访问） |
| **规律3** | 网络设备 = 块/帧 + 高速 + 共享（多进程共享同一网卡） |

#### 交叉特例（选择题陷阱）

| 特例 | 说明 |
|:---|:---|
| **磁带 = 块设备但独占** | 块设备通常共享，但磁带因顺序访问特性只能独占 |
| **打印机 = 字符设备但中速** | 字符设备通常低速，但打印机可中速 |
| **网卡 = 字符还是块？** | 传输单位是"帧"（块级），有的教材归字符设备——以教材为准 |
| **键盘 = 独占还是共享？** | 通常算独占（一次一个进程接收输入），但多进程可竞争读取 |

> [!warning] 强相关对应（非绝对）
> - 块设备 ↔ 高速；字符设备 ↔ 低速（大概率对应，非绝对）
> - 块设备 ↔ 可寻址；字符设备 ↔ 不可寻址（本质关联）
> - 独占 ↔ 字符/人机交互；共享 ↔ 块/存储

### I/O 接口（设备控制器）的三部分结构

I/O 接口 = **设备控制器**，是连接主机与外设的部件。从结构上分为三部分：

```
┌─────────────────────────────────────────────────────┐
│                    设备控制器                          │
│                                                      │
│  ┌──────────────────┐  ┌──────────────────────────┐  │
│  │ ① 设备控制器与CPU  │  │ ② 设备控制器与设备的接口  │  │
│  │     的接口         │  │      （一个控制器可接     │  │
│  │                   │  │       多个同类设备）      │  │
│  │  数据线/控制线/地址线│  │                        │  │
│  │  数据寄存器         │  │   设备1 ←→ 控制/数据/状态 │  │
│  │  控制寄存器         │  │   设备2 ←→ 控制/数据/状态 │  │
│  │  状态寄存器         │  │   ...                   │  │
│  └─────────┬─────────┘  └──────────┬───────────────┘  │
│            │                        │                  │
│            └──────────┬─────────────┘                  │
│                  ┌────┴─────┐                          │
│                  │ ③ I/O逻辑 │  ← 接口的"大脑"          │
│                  │          │                          │
│                  │ 命令译码   │                          │
│                  │ 设备地址译码│                          │
│                  │ 控制逻辑   │                          │
│                  └──────────┘                          │
└─────────────────────────────────────────────────────┘
```

#### ① 设备控制器与 CPU 的接口（面向主机侧）

| 组成 | 说明 |
|:---|:---|
| **数据线** | 数据在 CPU 与控制器之间传输 |
| **控制线** | 传送读/写命令、中断请求 |
| **地址线** | CPU 选择访问哪个寄存器/哪个控制器 |
| **数据寄存器** | 暂存 CPU 与设备间传输的数据 |
| **控制寄存器** | 存放 CPU 下达的控制命令 |
| **状态寄存器** | 记录设备当前状态（就绪/忙） |

> CPU 与设备控制器的交互 = **CPU 读写这三个寄存器**。

#### ② 设备控制器与设备的接口（面向设备侧）

| 特点 | 说明 |
|:---|:---|
| **一控多** | 一个设备控制器可连接**多个同类设备** |
| **设备有自己的地址** | 每个设备有自己的编号（如磁盘0、磁盘1） |
| **三类信号** | 控制、数据、状态信号在控制器与设备间传送 |

> 例：一个 SATA 控制器可接多个硬盘；一个 USB 控制器可接多个 USB 设备。

#### ③ I/O 逻辑（内部核心）

| 功能 | 说明 |
|:---|:---|
| **命令译码** | 解读 CPU 发来的命令（读/写/控制） |
| **设备地址译码** | 识别 CPU 要访问的是哪个设备 |
| **控制逻辑** | 协调 CPU 与设备的时序、中断、DMA 等 |

> I/O 逻辑 = 接口的"翻译官+调度员"：把 CPU 的命令翻译成设备能懂的控制信号，把设备的状态翻译成 CPU 能读的寄存器值。

### 机器寄存器 vs 外设寄存器（寄存器归属辨析）

> **寄存器 ≠ 存储器**。"寄存器"特指 CPU 内参与运算的快速存储单元（机器寄存器）和控制器内被端口寻址的单元（外设寄存器）；Cache、主存、磁盘都不是寄存器。

#### 存储层次全景

```
层级        位置        容量       是什么/不是什么
─────────────────────────────────────────────────────────────
① 机器寄存器   CPU 内      几十~几百B   是寄存器（CPU 自己的）
② Cache      CPU 内      几十KB~几十MB  ❌ 不是寄存器（SRAM 阵列）
③ 主存        内存条      几~几百GB     ❌ 不是寄存器（DRAM 单元）
④ 外存        磁盘/SSD    几百GB~几TB   ❌ 不是寄存器（存储介质）
⑤ 外设寄存器   设备控制器内  每设备几个   是寄存器（数据/状态/控制）
```

#### 两类寄存器对比

| | 机器寄存器（CPU 寄存器） | 外设寄存器（I/O 端口） |
|:---|:---|:---|
| **物理位置** | CPU 芯片内部 | 设备控制器内部 |
| **类别** | 通用（RAX/RBX...）、专用（PC/IR/SP）、标志（FLAGS）、控制（CR0~CR4）、MMU（页表基址/长度、TLB、重定位寄存器） | 数据寄存器、状态寄存器、控制寄存器 |
| **如何访问** | 寄存器名（汇编直接引用，如 `MOV RAX, RBX`） | 端口地址（IN/OUT 指令或内存映射地址） |
| **有无地址** | 无（只有寄存器编号） | **有端口地址**（如 0x60 键盘端口） |
| **数量** | 少（几十个） | 多（每个设备控制器都有三个） |
| **速度** | 最快（CPU 直接读写） | 较慢（通过总线访问） |

> [!warning] 易混点
> - **页表基址寄存器、TLB、重定位寄存器都是机器寄存器**（属于 CPU/MMU），不是外设寄存器
> - **Cache、主存、外存都不是寄存器**——它们是缓存/内存/存储介质
> - "除了 CPU 寄存器就全是外设寄存器"——**❌**，中间还隔着 Cache、主存、外存三层"非寄存器"存储

#### 本机举例（AMD Ryzen 9 8945HX + Windows）

| | 机器寄存器（CPU 内） | 外设寄存器（设备控制器内） |
|:---|:---|:---|
| 实例 | RAX、RIP、RFLAGS、CR3、TLB | 0x60 键盘端口、0x70 RTC 端口、NVMe 控制器寄存器 |
| 来源 | Ryzen 9 芯片 | 主板上的 USB/NVMe 控制器 |
| 访问 | `MOV RAX, RBX` | `IN AL, 0x64` |

**本机 I/O 端口实例**：
- 端口 `0x0000~0x000F` ← DMA 控制器
- 端口 `0x0060~0x0064` ← 键盘/PS2 控制器
- 端口 `0x0070~0x0071` ← RTC 实时时钟
- 端口 `0x0098` ← ACPI 电源管理
