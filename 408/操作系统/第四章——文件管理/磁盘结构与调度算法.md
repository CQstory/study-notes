# 磁盘结构与调度算法

## 4.2.1 磁盘结构

### 磁盘的物理结构

磁盘是计算机中最主要的外存设备，由一个或多个**盘片**组成，每个盘片有**两个面**（上下面），每个面有若干同心圆**磁道**，每个磁道又分为若干**扇区**。

```
        磁道（同心圆）
      ╭──────────────╮
     ╭┤  ╭────────╮  ├╮
    ╭┤ │ ╭──────╮ │ ├┤
   ╭┤ │ │ ╭──╮ │ │ │ ├╮
   │ │ │ │ │●│ │ │ │ │    ● = 读写磁头
   ╰┤ │ │ ╰──╯ │ │ │ ├╯
    ╰┤ │ ╰──────╯ │ ├╯
     ╰┤  ╰────────╯  ├╯
      ╰──────────────╯
        磁道（从外到内编号递增）
```

### 关键概念

| 概念 | 说明 |
|------|------|
| **磁道（Track）** | 盘片上的同心圆，从外到内编号递增（0号磁道在最外圈） |
| **柱面（Cylinder）** | 所有盘片上相同编号的磁道组成的圆柱面 |
| **扇区（Sector）** | 磁道被划分为若干弧段，每个弧段为一个扇区，是磁盘的最小物理存储单位 |
| **盘块（Block）** | 操作系统分配磁盘空间的基本单位，由若干连续扇区组成 |

### 磁盘地址

磁盘地址由以下部分组成：
$$磁盘地址 = (柱面号, 磁头号, 扇区号)$$

- **柱面号**：确定在哪一个柱面
- **磁头号**：确定在该柱面的哪一个盘面（磁道）
- **扇区号**：确定在该磁道的哪一个扇区

### 磁盘访问时间

磁盘访问一个数据块的时间由三部分组成：

$$T_{access} = T_{seek} + T_{rotation} + T_{transfer}$$

| 时间成分 | 说明 | 影响因素 |
|----------|------|----------|
| **寻道时间（Seek Time）** | 磁头移动到目标磁道的时间 | 磁盘调度算法主要优化此时间 |
| **旋转延迟（Rotational Latency）** | 等待目标扇区旋转到磁头下方的时间 | 磁盘转速 |
| **数据传输时间（Transfer Time）** | 读写数据的时间 | 数据量大小和磁盘转速 |

> **考点提示**：寻道时间是磁盘访问时间中最大、最可优化的部分，因此磁盘调度算法主要关注如何减少寻道时间。

### 磁盘分类

| 类型 | 说明 |
|------|------|
| **硬盘（HDD）** | 磁盘旋转，磁头移动，有机械运动 |
| **固态硬盘（SSD）** | 基于闪存，无机械运动，随机访问速度快 |
| **软盘** | 早期存储介质，已淘汰 |

## 4.2.2 磁盘调度算法

磁盘调度算法的目标是**减少平均寻道时间**。以下算法均假设磁头初始位置和请求队列已知。

### 算法一：先来先服务（FCFS, First Come First Served）

**基本思想**：按请求到达的先后顺序依次服务。

**特点**：
- 最简单的调度算法
- 公平，但效率低
- 磁头可能频繁大幅度移动

---

### 算法二：最短寻找时间优先（SSTF, Shortest Seek Time First）

**基本思想**：每次选择离当前磁头位置**最近**的请求进行服务。

**特点**：
- 性能优于FCFS
- 可能产生**饥饿**（远处请求长期得不到服务）

---

### 算法三：扫描算法（SCAN，电梯算法）

**基本思想**：磁头沿一个方向移动，服务途中经过的所有请求，到达边界后反向移动。

**特点**：
- 模拟电梯运行方式
- 不会饥饿
- 对刚经过的磁道请求不公平

---

### 算法四：循环扫描算法（C-SCAN, Circular SCAN）

**基本思想**：磁头沿一个方向移动服务请求，到达边界后**直接跳回起始端**（不是反向），再沿同一方向移动。

**特点**：
- 各位置请求的等待时间更均匀
- 不会饥饿

---

### 算法五：LOOK调度算法

**基本思想**：与SCAN类似，但磁头**不需要到达边界**，只需移动到当前方向上最远的请求处即可反向。

---

### 算法六：C-LOOK调度算法

**基本思想**：与C-SCAN类似，但磁头**不需要到达边界**，只需移动到当前方向上最远的请求处即可跳回。

---

### 计算示例（重要考点）

**题目**：假设磁盘有200个磁道（编号0~199），磁头当前在53号磁道，磁头正向磁道号增大的方向移动。请求队列为：98, 183, 37, 122, 14, 124, 65, 67。请分别用FCFS、SSTF、SCAN、C-SCAN、LOOK、C-LOOK算法计算磁头移动的总磁道数。

---

#### 1. FCFS算法

按请求到达顺序：98, 183, 37, 122, 14, 124, 65, 67

```
磁头移动轨迹：53 → 98 → 183 → 37 → 122 → 14 → 124 → 65 → 67

移动距离：
|98-53|  = 45
|183-98| = 85
|37-183| = 146
|122-37| = 85
|14-122| = 108
|124-14| = 110
|65-124| = 59
|67-65|  = 2

总移动距离 = 45 + 85 + 146 + 85 + 108 + 110 + 59 + 2 = 640
```

**FCFS总寻道长度 = 640**

---

#### 2. SSTF算法

每次选择最近的请求：

```
磁头移动轨迹：53 → 65 → 67 → 37 → 14 → 98 → 122 → 124 → 183

移动距离：
|65-53|  = 12
|67-65|  = 2
|37-67|  = 30
|14-37|  = 23
|98-14|  = 84
|122-98| = 24
|124-122|= 2
|183-124|= 59

总移动距离 = 12 + 2 + 30 + 23 + 84 + 24 + 2 + 59 = 236
```

**SSTF总寻道长度 = 236**

---

#### 3. SCAN算法（电梯算法）

磁头向增大方向移动，到达199后反向：

```
磁头移动轨迹：53 → 65 → 67 → 98 → 122 → 124 → 183 → 199 → 37 → 14

移动距离：
|65-53|   = 12
|67-65|   = 2
|98-67|   = 31
|122-98|  = 24
|124-122| = 2
|183-124| = 59
|199-183| = 16
|37-199|  = 162
|14-37|   = 23

总移动距离 = 12 + 2 + 31 + 24 + 2 + 59 + 16 + 162 + 23 = 331
```

**SCAN总寻道长度 = 331**

---

#### 4. C-SCAN算法

磁头向增大方向移动，到达199后直接跳回0：

```
磁头移动轨迹：53 → 65 → 67 → 98 → 122 → 124 → 183 → 199 → 0 → 14 → 37

移动距离：
|65-53|   = 12
|67-65|   = 2
|98-67|   = 31
|122-98|  = 24
|124-122| = 2
|183-124| = 59
|199-183| = 16
|0-199|   = 199
|14-0|    = 14
|37-14|   = 23

总移动距离 = 12 + 2 + 31 + 24 + 2 + 59 + 16 + 199 + 14 + 23 = 382
```

**C-SCAN总寻道长度 = 382**

---

#### 5. LOOK算法

磁头向增大方向移动，到达最远请求183后反向（不到边界）：

```
磁头移动轨迹：53 → 65 → 67 → 98 → 122 → 124 → 183 → 37 → 14

移动距离：
|65-53|   = 12
|67-65|   = 2
|98-67|   = 31
|122-98|  = 24
|124-122| = 2
|183-124| = 59
|37-183|  = 146
|14-37|   = 23

总移动距离 = 12 + 2 + 31 + 24 + 2 + 59 + 146 + 23 = 299
```

**LOOK总寻道长度 = 299**

---

#### 6. C-LOOK算法

磁头向增大方向移动，到达最远请求183后直接跳到最小请求14：

```
磁头移动轨迹：53 → 65 → 67 → 98 → 122 → 124 → 183 → 14 → 37

移动距离：
|65-53|   = 12
|67-65|   = 2
|98-67|   = 31
|122-98|  = 24
|124-122| = 2
|183-124| = 59
|14-183|  = 169
|37-14|   = 23

总移动距离 = 12 + 2 + 31 + 24 + 2 + 59 + 169 + 23 = 322
```

**C-LOOK总寻道长度 = 322**

---

### 六种算法对比总结

| 算法 | 总寻道长度 | 是否可能饥饿 | 磁头移动规则 |
|------|-----------|-------------|-------------|
| FCFS | 640 | 不会 | 按请求顺序 |
| SSTF | 236 | **会饥饿** | 总选最近的 |
| SCAN | 331 | 不会 | 到边界后反向 |
| C-SCAN | 382 | 不会 | 到边界后跳回起点 |
| LOOK | 299 | 不会 | 到最远请求后反向 |
| C-LOOK | 322 | 不会 | 到最远请求后跳回最小请求 |

### 算法对比要点

| 对比维度 | SCAN vs LOOK | C-SCAN vs C-LOOK |
|----------|-------------|-------------------|
| 区别 | SCAN到边界反向，LOOK到最远请求反向 | C-SCAN到边界跳回，C-LOOK到最远请求跳回 |
| 寻道长度 | LOOK < SCAN（少走无用距离） | C-LOOK < C-SCAN（少走无用距离） |
| 实际应用 | LOOK更实用 | C-LOOK更实用 |

> **考点提示**：
> 1. SSTF性能最好但会饥饿
> 2. SCAN/C-SCAN不会饥饿，但SCAN对中间位置请求更优
> 3. 实际系统中多使用LOOK和C-LOOK
> 4. **计算题务必画轨迹图，逐步计算**
