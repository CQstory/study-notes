# 第一章 计算机系统概述

---

## 1.1 计算机的发展历程

### 1.1.1 四代计算机

| 代次 | 时间 | 主要元器件 | 代表计算机 | 特点 |
|:----:|:----:|:----------:|:----------:|:-----|
| 第一代 | 1946-1957 | 电子管 | ENIAC、EDVAC | 体积大、功耗高、速度慢、可靠性差 |
| 第二代 | 1958-1964 | 晶体管 | IBM 7090、CDC 1604 | 体积减小、功耗降低、速度提升 |
| 第三代 | 1965-1971 | 中小规模集成电路 | IBM 360、PDP-8 | 体积进一步缩小、功能增强 |
| 第四代 | 1972-至今 | 大规模/超大规模集成电路 | 微型计算机、超级计算机 | 微型化、网络化、智能化 |

### 1.1.2 重要里程碑

- **1946年**：ENIAC（电子数值积分计算机）诞生，世界第一台通用电子计算机
- **1945年**：冯·诺依曼提出"存储程序"思想（EDVAC方案）
- **1971年**：Intel 4004，第一款微处理器
- **1981年**：IBM PC问世，个人计算机时代开启

> [!important] 考点
> 冯·诺依曼体系结构的核心思想是**存储程序**和**程序控制**，至今大多数计算机仍采用此架构。

## 1.2 计算机的分类

### 1.2.1 按用途分类

| 类型 | 说明 | 举例 |
|:-----|:-----|:-----|
| 个人计算机（PC） | 面向个人使用的通用计算机 | 台式机、笔记本、平板 |
| 服务器 | 为网络中其他计算机提供服务 | Web服务器、数据库服务器 |
| 嵌入式计算机 | 嵌入到其他设备中的专用计算机 | 智能手机、汽车电子、工业控制 |
| 超级计算机 | 具有极高运算能力的计算机 | 天河、神威·太湖之光 |

### 1.2.2 按体系结构分类（Flynn分类法）

| 分类 | 指令流 | 数据流 | 特点 |
|:-----|:------:|:------:|:-----|
| SISD | 单 | 单 | 单处理器，传统计算机 |
| SIMD | 单 | 多 | 向量处理器、GPU |
| MISD | 多 | 单 | 罕见，容错系统 |
| MIMD | 多 | 多 | 多处理器系统、多核处理器 |

> [!tip] 记忆技巧
> Flynn分类法：I = Instruction（指令），D = Data（数据），S = Single（单），M = Multiple（多）

## 1.3 计算机系统层次结构

### 1.3.1 冯·诺依曼架构

冯·诺依曼计算机的五大部件：

```
┌──────────────────────────────────────────────────┐
│                  运算器（ALU）                      │
│                                                    │
│  输入设备 ──→ 存储器 ←→ 控制器 ←→ 输出设备          │
│                  ↑    │                            │
│                  │    ↓                            │
│              运算器 ←─┘                            │
└──────────────────────────────────────────────────┘
```

**五大部件功能：**

| 部件 | 功能 | 说明 |
|:-----|:-----|:-----|
| 运算器 | 执行算术运算和逻辑运算 | ALU是核心，处理加减乘除、与或非等 |
| 控制器 | 指挥协调各部件工作 | 取指令、分析指令、执行指令 |
| 存储器 | 存放程序和数据 | 主存（内存）+ 辅存（外存） |
| 输入设备 | 将外部信息输入计算机 | 键盘、鼠标、扫描仪 |
| 输出设备 | 将计算结果输出 | 显示器、打印机 |

### 1.3.2 存储程序思想

> [!note] 核心概念
> 1. **程序和数据以二进制形式存放在存储器中**（存储程序）
> 2. **指令按顺序存放**，控制器按顺序从存储器中取出指令执行（程序控制）
> 3. **指令由操作码和地址码组成**
> 4. **以运算器为中心**（现代计算机已改为以存储器为中心）

### 1.3.3 计算机的工作过程

计算机的基本工作过程就是**不断执行指令**的过程：

```
取指令 → 分析指令 → 执行指令 → 取下一条指令 → ...
```

**详细步骤：**

1. **取指令（Fetch）**：根据PC（程序计数器）中的地址，从主存中取出指令送入IR（指令寄存器）
2. **分析指令（Decode）**：控制器对IR中的指令进行译码，确定操作类型和操作数地址
3. **执行指令（Execute）**：根据译码结果，从存储器或寄存器中取出操作数，送入ALU执行运算
4. **更新PC**：PC自动加1（或按转移指令修改），指向下一条指令

> [!example] 示例
> 执行 `ADD R1, R2` 指令：
> 1. 取指令：PC → MAR → 地址总线 → 主存 → 数据总线 → IR
> 2. 分析指令：控制器译码，识别为加法操作，操作数为R1和R2
> 3. 执行指令：R1 + R2 → R1（结果存回R1）
> 4. PC = PC + 1

## 1.4 性能指标

### 1.4.1 基本性能指标

#### 主频与时钟周期

| 指标 | 定义 | 关系 |
|:-----|:-----|:-----|
| 时钟周期（T） | CPU最小的时间单位 | T = 1 / f |
| 主频（时钟频率f） | CPU内部时钟的频率 | f = 1 / T |

- 单位：主频用GHz，时钟周期用ns
- 例：主频 3.0 GHz → 时钟周期 = 1 / (3.0 × 10^9) ≈ 0.33 ns

#### CPI（Clock cycles Per Instruction）

- **CPI** = 执行一条指令所需的平均时钟周期数
- CPI = 程序总时钟周期数 / 指令条数

#### CPU执行时间

$$T_{CPU} = 指令条数 \times CPI \times 时钟周期时间$$

$$T_{CPU} = \frac{指令条数 \times CPI}{主频}$$

> [!example] 计算示例
> 某计算机主频为 2 GHz，执行某程序共 10000 条指令，其中：
> - 4000条加法指令，CPI = 1
> - 3000条减法指令，CPI = 1
> - 2000条乘法指令，CPI = 3
> - 1000条除法指令，CPI = 4
>
> **平均CPI** = (4000×1 + 3000×1 + 2000×3 + 1000×4) / 10000 = 17000/10000 = 1.7
>
> **CPU执行时间** = 10000 × 1.7 / (2 × 10^9) = 17000 / (2 × 10^9) = 8.5 × 10^(-6) s = 8.5 μs

#### MIPS（Million Instructions Per Second）

$$MIPS = \frac{指令条数}{执行时间 \times 10^6} = \frac{主频}{CPI \times 10^6}$$

> [!warning] 注意
> MIPS只反映整数运算能力，不能反映浮点运算能力，不同指令集的MIPS不可直接比较。

#### FLOPS（Floating-point Operations Per Second）

- **FLOPS** = 每秒执行的浮点运算次数
- 常用单位：MFLOPS（10^6）、GFLOPS（10^9）、TFLOPS（10^12）

#### MFLOPS

$$MFLOPS = \frac{浮点运算次数}{执行时间 \times 10^6}$$

### 1.4.2 其他性能指标

| 指标 | 定义 | 说明 |
|:-----|:-----|:-----|
| 字长 | CPU一次能处理的二进制数据的位数 | 32位/64位 |
| 存储容量 | 存储器能存储的二进制信息量 | 主存容量 = 存储单元数 × 存储字长 |
| 数据通路带宽 | 数据总线一次能并行传送的信息位数 | 通常等于存储字长或倍数 |
| 吞吐量 | 单位时间内处理请求的数量 | 系统整体性能指标 |
| 响应时间 | 从发出请求到获得结果的时间 | 用户视角的性能指标 |

### 1.4.3 存储容量相关概念

- **MAR位数** 决定最大可寻址空间：最大寻址空间 = 2^MAR位数
- **MDR位数** = 存储字长
- 例：MAR = 32位，MDR = 64位 → 可寻址 2^32 = 4G 个存储单元，每个单元 64 位 = 8 字节

> [!important] 考点总结
> - CPU执行时间 = 指令条数 × CPI × T
> - MIPS = 主频 / (CPI × 10^6)
> - 注意区分主频、CPI、MIPS、FLOPS的含义和适用场景
> - 存储容量计算：地址位数决定寻址空间，数据位数决定存储字长

## 1.5 计算机系统的组成

### 1.5.1 硬件与软件

```
计算机系统
├── 硬件
│   ├── 主机
│   │   ├── CPU
│   │   │   ├── 运算器（ALU、寄存器组）
│   │   │   └── 控制器（CU、IR、PC、MAR、MDR）
│   │   └── 主存储器
│   └── 外设
│       ├── 输入设备
│       ├── 输出设备
│       └── 辅助存储器（外存）
└── 软件
    ├── 系统软件（操作系统、编译器、数据库管理系统）
    └── 应用软件
```

### 1.5.2 语言层次结构

从低级到高级：

| 层次 | 语言类型 | 说明 |
|:-----|:---------|:-----|
| 微程序机器层 | 微指令 | 由硬件直接执行 |
| 传统机器语言层 | 机器语言 | 0/1代码，由微程序解释 |
| 操作系统层 | 操作系统指令 | 由操作系统程序实现 |
| 汇编语言层 | 汇编语言 | 由汇编程序翻译为机器语言 |
| 高级语言层 | 高级语言 | 由编译程序翻译为机器语言 |

### 1.5.3 冯·诺依曼架构 vs 哈佛架构

| 特征 | 冯·诺依曼架构 | 哈佛架构 |
|:-----|:------------:|:--------:|
| 存储器结构 | 指令和数据共享同一存储器 | 指令和数据使用独立存储器 |
| 数据通路 | 共享总线 | 独立总线 |
| 优点 | 结构简单、成本低 | 可同时访问指令和数据，效率高 |
| 缺点 | 存在冯·诺依曼瓶颈 | 结构复杂、成本高 |
| 应用 | 通用计算机 | DSP、嵌入式系统 |

> [!note] 冯·诺依曼瓶颈
> CPU与存储器之间速度不匹配，CPU速度快而存储器速度慢，导致CPU需要等待存储器。

## 1.6 考点总结

### 高频考点

1. **冯·诺依曼体系结构**：存储程序、五大部件、以运算器为中心
2. **性能指标计算**：CPU执行时间、CPI、MIPS、FLOPS
3. **计算机发展四代**：电子管→晶体管→集成电路→超大规模集成电路
4. **Flynn分类法**：SISD、SIMD、MISD、MIMD
5. **存储容量计算**：MAR、MDR与寻址空间的关系

### 易错点

- 冯·诺依曼架构**以运算器为中心**（现代计算机以存储器为中心）
- 时钟周期和主频互为倒数关系
- MIPS不能跨指令集比较
- 字长指CPU一次能处理的数据位数，不等于存储字长
