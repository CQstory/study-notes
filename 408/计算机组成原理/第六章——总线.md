# 第六章 总线

---

## 6.1 总线的基本概念

### 6.1.1 总线的定义

- **总线**是连接计算机各部件的一组公共信息传输线
- 总线是多个部件共享的传输通道
- 同一时刻只允许一个部件向总线发送信息，但多个部件可以同时接收信息

### 6.1.2 总线的特性

| 特性 | 说明 |
|:-----|:-----|
| 物理特性 | 总线的物理连接方式（线缆、插头、插座等） |
| 功能特性 | 每根线的功能（地址线、数据线、控制线） |
| 电气特性 | 信号的传递方向、电平标准 |
| 时间特性 | 信号的时序关系 |

### 6.1.3 总线的优缺点

| 优点 | 缺点 |
|:-----|:-----|
| 简化系统结构 | 同一时刻只能有一个发送方 |
| 便于系统扩展 | 带宽受限 |
| 降低系统成本 | 总线竞争可能导致延迟 |
| 标准化设计 | 成为系统性能瓶颈 |

---

## 6.2 总线的分类

### 6.2.1 按功能层次分类

```
┌─────────────────────────────────────────────┐
│              片内总线                         │
│     （芯片内部，连接CPU内部各部件）              │
├─────────────────────────────────────────────┤
│              系统总线                         │
│     （连接CPU、主存、I/O接口）                  │
│     ├── 数据总线                              │
│     ├── 地址总线                              │
│     └── 控制总线                              │
├─────────────────────────────────────────────┤
│              通信总线                         │
│     （连接计算机之间或计算机与外设之间）          │
│     （USB、PCIe、SATA等）                     │
└─────────────────────────────────────────────┘
```

| 总线类型 | 位置 | 功能 | 说明 |
|:---------|:-----|:-----|:-----|
| 片内总线 | CPU芯片内部 | 连接寄存器、ALU等 | 距离短、速度快 |
| 系统总线 | 主板上的系统级总线 | 连接CPU、主存、I/O接口 | 计算机内部通信 |
| 通信总线 | 计算机之间/计算机与外设 | 远程通信 | USB、PCIe、SATA等 |

### 6.2.2 系统总线的组成

系统总线按功能分为三组：

#### 数据总线（Data Bus）

- **功能**：传输数据信息
- **方向**：双向
- **宽度**：决定每次传输的数据位数（如32位、64位）
- **特点**：数据总线宽度决定了系统的数据处理能力

#### 地址总线（Address Bus）

- **功能**：传输地址信息
- **方向**：单向（CPU→存储器/I/O）
- **宽度**：决定可寻址的存储空间大小
- **特点**：n根地址线可寻址 2^n 个存储单元

> [!example] 地址总线与寻址空间
> - 32根地址线 → 可寻址 2^32 = 4GB 空间
> - 64根地址线 → 可寻址 2^64 空间（理论上）

#### 控制总线（Control Bus）

- **功能**：传输控制信号和时序信号
- **方向**：部分单向，部分双向
- **常见信号**：

| 信号 | 方向 | 功能 |
|:-----|:----:|:-----|
| 读信号（RD） | CPU→外 | 通知存储器/I/O执行读操作 |
| 写信号（WR） | CPU→外 | 通知存储器/I/O执行写操作 |
| 存储器请求（MREQ） | CPU→外 | 访问存储器 |
| I/O请求（IORQ） | CPU→外 | 访问I/O设备 |
| 总线请求（BR） | 外→CPU | 申请总线使用权 |
| 总线应答（BG） | CPU→外 | 总线使用权授予 |
| 中断请求（INTR） | 外→CPU | 请求中断 |
| 中断应答（INTA） | CPU→外 | 中断应答 |
| 时钟信号（CLK） | CPU→外 | 同步时序 |

### 6.2.3 按数据传输方式分类

| 类型 | 说明 | 举例 |
|:-----|:-----|:-----|
| 并行总线 | 多位数据同时传输 | ISA、PCI |
| 串行总线 | 数据逐位传输 | USB、SATA、PCIe |

### 6.2.4 按时序方式分类

| 类型 | 说明 | 优缺点 |
|:-----|:-----|:-------|
| 同步总线 | 使用统一的时钟信号同步 | 速度快，但时钟频率受最长线路限制 |
| 异步总线 | 使用握手协议（请求-应答） | 灵活，不受时钟限制，但速度慢 |
| 半同步总线 | 同步基础上增加等待信号 | 兼顾速度和灵活性 |

## 6.3 总线仲裁方式

当多个设备同时请求使用总线时，需要通过**总线仲裁**来决定总线的使用权。

### 6.3.1 集中仲裁

仲裁逻辑集中在一处（如CPU或总线控制器中）。

#### 链式查询（菊花链查询）

```
总线请求 ──→ 总线忙 ──→ BG ──→ 设备1 ──→ 设备2 ──→ 设备3
                        ↑          ↑          ↑
                      离仲裁器最近的设备优先级最高
```

- **工作原理**：总线授权信号（BG）串行通过各设备，离仲裁器最近的设备优先级最高
- **优点**：结构简单，扩展容易，控制线少（3根：BR、BG、BS）
- **缺点**：
  - 优先级固定，离仲裁器远的设备难以获得总线
  - 对电路故障敏感（一个设备故障会影响后续设备）
  - 速度慢（BG信号需要逐级传递）

#### 计数器定时查询

```
总线请求 ──→ 设备地址计数器 ──→ 设备地址线 ──→ 各设备
```

- **工作原理**：总线仲裁器中有一个计数器，计数器值通过设备地址线发送，与设备号匹配的设备获得总线
- **计数方式**：
  - 从0开始计数：优先级与设备号相关（类似链式查询）
  - 从上次停止处开始计数：优先级循环，公平性好
- **优点**：优先级可调，比链式查询灵活
- **缺点**：需要额外的设备地址线（log2(n)根），速度仍受计数影响

#### 独立请求方式

```
设备1 ──BR1──→ ┌─────────┐
设备2 ──BR2──→ │  总线    │──BG1──→ 设备1
设备3 ──BR3──→ │  仲裁器  │──BG2──→ 设备2
               │         │──BG3──→ 设备3
               └─────────┘
```

- **工作原理**：每个设备有独立的总线请求（BR）和总线授权（BG）线
- **优点**：
  - 速度最快（仲裁时间固定）
  - 优先级可以灵活设置
  - 不受设备故障影响
- **缺点**：控制线数量多（2n根），硬件复杂

#### 三种集中仲裁方式对比

| 特征 | 链式查询 | 计数器定时查询 | 独立请求方式 |
|:-----|:--------:|:------------:|:------------:|
| 控制线数量 | 3根 | log2(n)+2根 | 2n根 |
| 速度 | 最慢 | 中等 | 最快 |
| 优先级 | 固定 | 可调 | 灵活 |
| 扩展性 | 好 | 中等 | 差 |
| 硬件复杂度 | 低 | 中 | 高 |
| 故障敏感性 | 高 | 低 | 低 |

> [!important] 考点
> - 链式查询：3根线（BR、BG、BS），优先级固定，离仲裁器近的优先
> - 计数器定时查询：log2(n)+2根线，优先级可调
> - 独立请求：2n根线，速度最快，但硬件复杂

### 6.3.2 分布仲裁

- **原理**：不需要中央仲裁器，每个设备都有自己的仲裁号和仲裁逻辑
- **工作方式**：各设备通过竞争方式获取总线使用权
- **常见方法**：
  - 自举分布式仲裁：各设备将自己的仲裁号发送到总线上，编号最大的设备获得总线
  - 冲突检测分布式仲裁：类似以太网的CSMA/CD
- **优点**：可靠性高，无单点故障
- **缺点**：控制逻辑复杂

## 6.4 总线操作周期

### 6.4.1 总线操作的基本过程

一次总线操作（总线事务）通常包含以下步骤：

```
1. 总线请求（Request）    → 申请总线使用权
2. 总线仲裁（Arbitration）→ 决定总线使用权归属
3. 寻址（Addressing）      → 发送目标地址
4. 数据传输（Transfer）    → 传输数据
5. 结束（Ending）          → 释放总线
```

### 6.4.2 总线通信方式

#### 同步通信

- 使用统一的时钟信号，所有操作在固定时钟周期内完成
- **优点**：控制简单，速度快
- **缺点**：时钟频率受最长传输路径限制，灵活性差

#### 异步通信

- 使用握手信号（请求/应答）进行通信
- **三种握手方式**：

| 握手方式 | 说明 |
|:---------|:-----|
| 不互锁 | 主方发出请求后不等应答，直接执行 |
| 半互锁 | 主方发出请求后等待从方应答 |
| 全互锁 | 主方和从方互相等待确认 |

- **优点**：灵活，不受时钟限制
- **缺点**：控制复杂，速度慢

### 6.4.3 总线带宽

$$总线带宽 = \frac{数据宽度}{总线周期}$$

> [!example] 总线带宽计算
> 某总线时钟频率为 200MHz，总线宽度为 32位
> - 总线周期 = 1/200MHz = 5ns
> - 每个周期传输 32位 = 4字节
> - 总线带宽 = 4B / 5ns = 4B × 200 × 10^6 = 800MB/s

> [!example] 更复杂的带宽计算
> 某同步总线时钟频率为 100MHz，宽度为 32位
> - 每个总线周期（5个时钟周期）完成一次传输
> - 实际传输速率 = 32位 / (5 × 10ns) = 4B / 50ns = 80MB/s

## 6.5 总线标准

### 6.5.1 常见总线标准

| 总线标准 | 类型 | 宽度 | 频率 | 带宽 | 应用 |
|:---------|:----:|:----:|:----:|:----:|:-----|
| ISA | 并行 | 16位 | 8MHz | 16MB/s | 早期PC |
| EISA | 并行 | 32位 | 8.3MHz | 33MB/s | 早期服务器 |
| PCI | 并行 | 32/64位 | 33/66MHz | 133~533MB/s | PC扩展卡 |
| PCI-E（PCIe） | 串行 | ×1~×16 | 2.5/5/8GT/s | 250MB/s~16GB/s | 现代PC |
| USB | 串行 | 1对差分 | 1.5/12/480/5/10Gbps | — | 外设连接 |
| SATA | 串行 | 1对差分 | 1.5/3/6Gbps | 150~600MB/s | 硬盘/SSD |
| AGP | 并行 | 32位 | 66MHz | 2.1GB/s | 显卡（已淘汰） |

### 6.5.2 总线标准的发展趋势

- 从并行总线向串行总线发展（PCIe取代PCI）
- 传输速率不断提高
- 支持热插拔和即插即用
- 向点对点通信发展（取代共享总线）

## 6.6 考点总结

### 高频考点

1. **总线的分类**：片内总线、系统总线（数据/地址/控制总线）、通信总线
2. **总线仲裁方式**：链式查询、计数器定时查询、独立请求方式的对比
3. **总线带宽计算**：带宽 = 数据宽度 / 总线周期
4. **集中仲裁 vs 分布仲裁**：特点对比
5. **同步通信 vs 异步通信**：握手方式

### 易错点

- 地址总线是单向的（CPU→存储器/I/O），数据总线是双向的
- 链式查询中离仲裁器最近的设备优先级最高
- 控制总线中有些信号是单向的，有些是双向的
- 总线带宽计算时注意单位统一
- 独立请求方式需要2n根控制线（n为设备数）

### 常用公式速查

| 公式 | 说明 |
|:-----|:-----|
| 总线带宽 = 数据宽度 / 总线周期 | 带宽计算 |
| 总线周期 = 1 / 总线频率 | 周期计算 |
| 链式查询控制线 = 3根 | BR、BG、BS |
| 独立请求控制线 = 2n根 | n个设备 |
| 计数器定时查询控制线 = log2(n) + 2根 | 设备地址线+BR+BS |
