# 第三章 存储器层次结构

---

## 3.1 存储器的分类

### 3.1.1 按层次分类（存储器层次结构）

```
┌─────────────────────────────────────────────────┐
│  寄存器（CPU内部）                                 │
│  速度最快、容量最小、价格最高                        │
├─────────────────────────────────────────────────┤
│  Cache（高速缓存）                                  │
│  速度快、容量小、价格高                             │
├─────────────────────────────────────────────────┤
│  主存储器（内存/RAM + ROM）                         │
│  速度中等、容量中等、价格中等                        │
├─────────────────────────────────────────────────┤
│  辅助存储器（外存/硬盘、SSD、光盘）                   │
│  速度最慢、容量最大、价格最低                        │
└─────────────────────────────────────────────────┘
```

| 层次 | 速度 | 容量 | 价格 | 易失性 |
|:-----|:----:|:----:|:----:|:------:|
| 寄存器 | 最快 | 最小（几百字节） | 最高 | 易失 |
| Cache | 很快 | 较小（KB~MB） | 很高 | 易失 |
| 主存 | 中等 | 中等（GB级） | 中等 | RAM易失，ROM非易失 |
| 辅存 | 最慢 | 最大（TB级） | 最低 | 非易失 |

> [!note] 局部性原理
> 存储器层次结构的基础是**局部性原理**：
> - **时间局部性**：最近访问的数据很可能再次被访问
> - **空间局部性**：访问某地址后，很可能访问其附近地址

### 3.1.2 按存储介质分类

| 类型 | 特点 | 举例 |
|:-----|:-----|:-----|
| 半导体存储器 | 速度快、体积小 | RAM、ROM、Cache |
| 磁表面存储器 | 容量大、速度慢 | 硬盘、磁带 |
| 光存储器 | 容量大、成本低 | CD、DVD、蓝光 |

### 3.1.3 按存取方式分类

| 类型 | 特点 | 举例 |
|:-----|:-----|:-----|
| 随机存取存储器（RAM） | 任意单元存取时间相同 | SRAM、DRAM |
| 只读存储器（ROM） | 只能读取不能写入（或需特殊方式写入） | PROM、EPROM、EEPROM、Flash |
| 串行访问存储器 | 按顺序存取 | 磁带 |
| 直接存取存储器（DAM） | 先定位到区域，再顺序查找 | 磁盘 |
| **相联存储器（CAM）** | 按内容寻址，所有单元并行比较 | TLB、全相联Cache的标记比较 |

### 3.1.4 相联存储器（CAM，按内容寻址）

相联存储器是一种**按内容寻址**的存储器：普通存储器是"给地址→查数据"，相联存储器是"**给数据（或部分数据）→查它在哪儿**"。

#### 结构组成（与普通存储器的本质区别：每单元带比较电路）

| 组成部分 | 作用 |
|:-----|:-----|
| 存储体 | 存放数据 |
| 相联电路（比较器） | 每个单元一个，与给定内容**并行比较** |
| 屏蔽寄存器（掩码） | 指定只比较内容的某几位，其余位不参与比较 |
| 优先编码器 | 多个单元同时匹配时，选出优先级最高的一个 |

#### 读写方式与优缺点

- **写入**：与普通存储器相同，把数据存入某单元
- **读出**：给出检索字，所有单元**同时比较**，匹配成功的单元直接输出内容/地址，查找时间与容量无关，**速度极快**
- **优点**：按内容查找、并行比较，访问速度高（查找时间固定）
- **缺点**：每单元都需比较电路，**硬件复杂、成本高、集成度低、功耗大**，只做小容量

#### 在408中的三个应用点（考试最爱）

| 应用场景 | 说明 |
|:-----|:-----|
| **TLB（快表）** | TLB就是一块相联存储器：给出虚页号，所有表项并行比较，命中直接输出实页号 |
| **全相联映射的Cache** | 主存块可放任意行，命中判断需所有行的Tag同时比较，硬件实现就是相联存储器 |
| **组相联映射** | 组间用直接映射（算出组号），组内n个Tag用相联方式并行比较 |

> [!important] 易混辨析：相联存储器 ≠ 相联映射（408高频考点）
> | 概念 | 属于什么 | 含义 |
> |:-----|:-----|:-----|
> | 相联存储器 | 一种**存储器件**（硬件） | 按内容寻址的存储器（CAM） |
> | 相联映射 | Cache的一种**映射方式**（策略） | 主存块可放入Cache任意行 |
>
> 二者关系：**相联映射的策略，靠相联存储器的硬件来实现**；页表本身存主存，但TLB是相联存储器

## 3.2 主存储器

### 3.2.1 SRAM与DRAM对比

| 特征 | SRAM（静态RAM） | DRAM（动态RAM） |
|:-----|:---------------:|:---------------:|
| 存储元件 | 触发器（6管） | 电容（1管1电容） |
| 是否需要刷新 | 不需要 | 需要 |
| 存取速度 | 快（~1ns） | 较慢（~10ns） |
| 集成度 | 低 | 高 |
| 功耗 | 大 | 小 |
| 价格 | 高 | 低 |
| 用途 | Cache | 主存 |

> [!important] 考点
> - SRAM用触发器存储信息，不需要刷新，速度快但集成度低
> - DRAM用电容存储信息，需要定期刷新，速度慢但集成度高
> - Cache用SRAM，主存用DRAM

#### DRAM的现代形态：SDRAM与DDR

**SDRAM（Synchronous DRAM，同步动态存储器）**：与系统时钟**同步**工作的DRAM，所有操作由时钟边沿驱动、按固定节拍完成——现代主存（含本机 DDR5）都是 SDRAM 家族。

| | 异步DRAM（传统） | SDRAM（同步） |
|:---|:---|:---|
| 控制方式 | RAS̄/CAS̄脉冲触发，时序不固定 | 时钟边沿驱动，节拍可预测 |
| CPU等待 | 发读命令后必须死等 | 控制器知道第几个时钟沿数据到，不必等 |
| 访问流程 | 行列地址复用+脉冲选通 | 命令集：ACTIVE→READ/WRITE→PRECHARGE |
| 内部结构 | 单存储体 | **多bank交替工作** |

- **多bank交替**：bank0传数据时bank1正在预充电/激活下一行；bank号藏在地址低位——即**低位交叉编址思想在芯片内部的实现**（见3.2.5）；DDR5 已发展到 32 个 bank

**SDRAM → DDR 演进**：

| 代际 | 关键改进 |
|:-----|:-----|
| SDR SDRAM | 时钟单边沿传数据，带宽 = 时钟频率 × 位宽 |
| **DDR**（双倍数据速率） | **上升沿+下降沿都传数据**，同时钟频率带宽×2 |
| DDR2/3/4 | 预取位数翻倍、电压降低 |
| DDR5（本机） | 预取16位（BL16，一次读命令=64B缓存行）、双子通道 |

> [!important] 考点浓缩
> - SDRAM 的 "S" = **与时钟同步**，延迟可预测，CPU 不必等待
> - DDR 的"双倍" = **时钟双沿传输**，等效频率是实际时钟的 2 倍（DDR5-5600：实际时钟≈ 2600 MHz，等效 5600 MT/s，见[[专题01——周期|专题01]]）
> - **SRAM ≠ SDRAM**：名字像但本质不同——SRAM（Cache，触发器，不刷新）；SDRAM（主存，电容，要刷新，只是同步化）

### 3.2.2 DRAM刷新与引脚复用

#### 为什么要刷新

- DRAM 单元是 **1管1电容**：电荷会泄漏，数据保持时间只有约 **2 ms**，必须在 2ms 内把所有行"充电续命"一遍
- 对比：SRAM 是触发器双稳态，不漏电，**永不刷新**（Cache 用 SRAM 的原因之一）

#### 引脚复用（行/列地址分时复用）

大容量 DRAM 地址位多，而**引脚是封装成本和布线的硬约束**，行列复用使地址引脚减半：

```
第1拍：地址引脚 = 行地址 ─RAS̄（行选通）有效─► 行地址锁存器 → 行译码 → 选中字线
第2拍：地址引脚 = 列地址 ─CAS̄（列选通）有效─► 列地址锁存器 → 列译码 → 选中位线
```

- 同一批引脚先来行地址、后来列地址，芯片内两个锁存器分别保存
- **地址引脚数 = max(行位数, 列位数) ≈ N/2**

> [!example] 引脚复用计算示例
> 64M × 8 位 DRAM 芯片：
> - 字数 64M = 2^26，完整地址需 26 位
> - 内部组织 8192 行 × 8192 列（2^13 × 2^13）
> - 行地址 13 位 + 列地址 13 位，**复用后地址引脚只要 13 根**（不复用要 26 根）

代价：地址分两拍送，访存延迟略增——用时间换引脚，对慢速主存划算（Cache 用 SRAM 不搞复用，速度优先）。

#### 刷新的三个关键性质（考点密集区）

| 性质 | 内容 |
|:-----|:-----|
| **以行为单位** | 激活字线 → 该行所有单元电荷上到位线 → 灵敏放大器放大并**回写恢复**（即"读出再生"），与列地址无关 |
| **不需要 CPU** | 刷新地址由**刷新计数器**产生（芯片内或内存控制器中），按 0,1,2… 逐行扫，CPU 不参与 |
| **对 CPU 透明** | 刷新与 CPU 访存互不相干（异步刷新时），CPU 感知不到刷新在发生 |

#### 三种刷新方式对比

设：共 N 行，存储周期 T，刷新周期 2ms：

| 方式 | 做法 | 死区 | 优缺点 |
|:-----|:-----|:-----|:-----|
| **集中刷新** | 2ms 内划出一段时间连续刷新全部 N 行 | 死区 = **N × T** | 死区内不能访存，其余时间连续读写 |
| **分散刷新** | 每个读写周期后顺带刷一行 | 无死区 | 存储周期变长（读写+刷新），速度慢 |
| **异步刷新**（最常用） | 每隔 **2ms / N** 刷一行，摊匀到整个周期 | 每次只停 1 个 T | 折中方案，实际机器都用它 |

> [!example] 刷新计算模板（128 行、T = 0.5 μs）
> - **集中刷新**：死区 = 128 × 0.5 μs = **64 μs**（每 2ms 里有 64μs 不能访存）
> - **分散刷新**：存储周期 = 0.5 + 0.5 = **1 μs**，2ms 内可刷 2000 次 > 128 行 ✓
> - **异步刷新**：刷新间隔 = 2 ms ÷ 128 ≈ **15.6 μs** 刷一行
>
> 另例：64K × 1 位芯片按 128 × 512 矩阵组织，若每次刷新操作需 100ns，则集中刷新死区 = 128 × 100ns = **12.8 μs**

#### 复用与刷新的交汇点：RAS-only 刷新

刷新恰好**只需要行地址**，而行地址引脚和 RAS̄ 本来就有：

- 刷新计数器把行号放上地址引脚，**只发 RAS̄、不发 CAS̄**（RAS-only 刷新），芯片内部自动完成"读出再生"
- 引脚复用省下的正是列地址那一拍，而刷新根本不用列地址 → **复用对刷新零妨碍**

> [!note] 高温刷新（了解）
> 温度越高漏电越快：DDR 内存有高温加倍刷新模式，超过 85°C 时刷新频率翻倍（"刷新周期 2ms"指常温）。实机上刷新由 CPU 内的**内存控制器**定期发 REF 命令完成，对操作系统和程序完全透明。

### 3.2.3 存储器芯片结构

#### 五大组成部件

```
              地址总线
                │
        ┌──────▼───────┐
        │  地址译码器    │──行译码→ 字线（选中一行存储单元）
        │（行译码+列译码）│──列译码→ 位线选通
        └──────┬───────┘
                ▼
        ┌─────────────────┐
        │   存储体          │  存储单元矩阵（每格1位）
        │  字线 × 位线      │  SRAM:6管触发器 / DRAM:1管1电容
        └───────┬─────────┘
                │ 位线（微弱信号）
        ┌───────▼────────┐
        │ 读写电路（IO）  │◄──► 数据线 ↔ 数据总线
        │ 灵敏放大器/驱动 │
        └────────────────┘
  CS̄（片选）、WĒ（写允许）、OĒ（输出允许）← 控制线
```

| 部件 | 作用 | 要点 |
|:-----|:-----|:-----|
| 存储体 | 存储单元矩阵，每单元存1位 | SRAM 6管触发器；DRAM 1管1电容（会漏电→刷新，见3.2.2） |
| 地址译码器 | 地址→选中字线（+列选通） | 单译码/双译码见下 |
| 读写电路（IO） | 位线与数据总线间的中继 | 灵敏放大器（放大+DRAM回写恢复）、写驱动器、三态门 |
| 片选线 CS̄ | 决定本片芯片参不参与 | 无效时IO呈**高阻断开**（不是输出0）；由高位地址译码产生（字扩展，见3.2.4） |
| 读写控制线 WĒ/OĒ | 决定方向 | WĒ=0写/1读；OĒ=0才允许数据上总线，写时OĒ无效 |

- **地址线**：决定可寻址的存储单元数
- **数据线**：决定每个存储单元的位数

#### 字线与位线

- **字线数 = 字数，位线数 = 字长**（逻辑视角）
- 一根字线同时连接一个字的 b 个单元（分挂在 b 根位线上），字线有效即整字并行读出；一根位线串起所有字的同一位
- 字线数 × 位线数 = 单元总数 = 字数 × 字长
- 大容量芯片必然用二维矩阵：译码规模从 2^N 降到 2×2^(N/2)
- DRAM：存储体分多个 bank 可并行；行/列地址**分时复用**同一批引脚（RAS̄/CAS̄锁存，详见3.2.2），地址引脚数 = max(行位数, 列位数)

#### 单译码 vs 双译码

| | 单译码 | 双译码 |
|:---|:---|:---|
| 译码方式 | N位地址 → 2^N 根字线 | 拆行 N/2 + 列 N/2：行译码选行、列译码选位 |
| "字线"概念 | 字线即选择线，字线数=字数严格成立 | 拆成行选择线+列选择线，物理字线数大减 |
| 例 | 64×8：64根字线 | 64K×8：256行×256列，共512根选择线 |
| 适用 | 小容量芯片 | 大容量芯片 |

#### 四类线路的连接关系

| 线路 | 位置 | 方向 | 连接关系 |
|:-----|:-----|:-----|:-----|
| 地址总线 | 芯片外（系统级） | CPU→芯片 | MAR→地址总线→**地址引脚**→译码器 |
| 字线 | 芯片内，横向 | 译码器→存储体 | 有效时接通一个字的全部单元 |
| 位线 | 芯片内，纵向 | 存储体→读写电路 | 通向灵敏放大器 |
| 数据总线 | 芯片外（系统级） | 双向 | MDR↔数据总线↔**数据引脚**（经三态门）↔读写电路 |

两个衔接点：**地址引脚**（总线→译码器入口）、**数据引脚**（读写电路→总线出口，带三态门）。字线、位线不出芯片。

#### 一次读取的完整时序

```
① MAR → 地址总线 → 地址引脚（地址出发）
② CS̄ 有效，本片芯片被选中（芯片激活）
③ 译码器译码 → 字线有效，双译码再加列选通（定位）
④ 该字 b 个单元导通 → 电平上到位线（内容就位，信号微弱）
⑤ 灵敏放大器放大位线信号（DRAM读出破坏性，放大兼回写恢复）
⑥ WĒ=1（读）、OĒ有效 → 三态门导通（数据出芯片）
⑦ 数据总线电平稳定 → 时钟沿 → MDR 锁存（01固定下来）
⑧ 恢复时间（位线预充电、总线释放）→ 一个完整存储周期结束
```

> [!important] 核心认知：电平即 01，不存在"转化"
> - 高电平本身就被定义为1，低电平定义为0：总线上的电平**已经是** 01 序列，只是以电压形式存在
> - **MDR 只做锁存**（时钟沿把总线电平"拍照"存进触发器），没有任何翻译/编码/转换过程
> - 全数字系统中流动的一直是"电平形态的 01"，寄存器只是把流动的 01 固定下来

#### 存取周期与连续读取

- **译码方式（单/双）不改变存取周期**：它只是芯片内部结构差异，读一个字都是一个存取周期
- 读连续字节数组（如 `char[10]`）的周期数取决于**字长**与**对齐**：

| 字长 | 10字节的分法 | 访存次数 |
|:----:|:-----|:----:|
| 8位 | 1×10 | 10 |
| 32位 | 4+4+2 | 3 |
| 64位 | 8+2 | 2 |

- 公式：次数 = ⌈总字节数 / 字长⌉（前提字对齐）；**未对齐可能多读一次**
- 实机视角：CPU 只发一条 load，Cache 未命中时按**缓存行 64B** 整行调入；DDR5 一次读命令突发传输 BL16（子通道32位×16拍 = 64B），物理上只需 1 个存取周期（数组跨两条缓存行时才需 2 次）

#### 引脚数计算

以 **64K × 8 位**芯片为例：

| 引脚 | 根数 | 计算 |
|:-----|:----:|:-----|
| 地址线 | 16 | log₂(64K)=16（若DRAM行列复用则减半为8） |
| 数据线 | 8 | 字长 |
| 控制线 | 3 | CS̄、WĒ、OĒ |

> [!example] 存储容量计算
> 某存储器芯片有 20 根地址线，8 根数据线
> - 存储容量 = 2^20 × 8 = 1M × 8bit = 1MB

> [!important] 易错点
> - DRAM 地址引脚数 ≠ log₂字数：行列复用后按行/列地址较多者算（还要扣除bank位）
> - 片选无效 = 高阻断开，不是数据为0
> - 字线数=字数只在单译码/逻辑视角严格成立；双译码下物理字线退化为行选择线
> - 位扩展：各芯片共用地址线和片选，数据线（位线）各接各的；字扩展：高位地址译码产生片选（见3.2.4）
> - 存储周期 > 存取时间（含⑧恢复时间，见[[专题01——周期|专题01]]）

#### 按字节编址与按字编址

**解题第一步永远是算总容量（位）**，再按编址单位换算地址数：

$$按字节编址地址数 = \frac{总位数}{8} = 总字节数$$

$$按字编址地址数 = \frac{总位数}{字长} = \frac{总字节数}{字长/8}$$

> [!example] 计算例题：4 片 512K×8 芯片，机器字长 32 位
> - 总容量 = 4 × 512K × 8位 = 2^2 × 2^19 × 2^3 = **2^24 位 = 2^21 字节 = 2 MB**
> - 按字节编址：2^24 ÷ 8 = **2^21 个地址**（地址线/MAR 21 位）
> - 按字编址（字长32位）：2^21 ÷ 4 = **2^19 个地址**（地址线/MAR 19 位）
> - 易错：2^24 是**总位数（16 Mbit）**，不是字节地址数！

**两种编址的内在关系**：同一存储体，只是地址粒度不同

```
按字节编址（21位地址）：
| 字地址（高19位） | 字节内偏移（低2位） |
```

- 字节地址 = 字地址 × 每字字节数 + 字内偏移（32位字：低2位为偏移）
- 按字编址地址数 = 按字节编址地址数 ÷ (字长/8)，地址线少 log₂(字长/8) 根

**三个"字长"辨析**（选择题陷阱）：

| 概念 | 含义 |
|:-----|:-----|
| 机器字长 | CPU 一次能处理的位数（ALU/通用寄存器宽度） |
| 存储字长 | 一个存储单元的位数 |
| 数据字长 | 数据总线一次传送的位数 |

若 4 片 512K×8 做**位扩展**（见3.2.4），存储字长恰好也是 32 位（4片×8位并联），"一个存储单元 = 一个机器字"，1 个周期读出一个 32 位字。

### 3.2.4 存储器的扩展

#### 通用框架：先算芯片数和分组

用 **m字×b位** 的小芯片构造 **M字×B位** 的目标存储器：

$$芯片总数 = \frac{M \times B}{m \times b} = \underbrace{\frac{M}{m}}_{组数（字扩展方向）} \times \underbrace{\frac{B}{b}}_{每组芯片数（位扩展方向）}$$

地址位分配永远是：**高位 = 组选（进译码器→片选），低位 = 组内地址（组内芯片共用）**

#### 位扩展（增加字长）

**规则：所有芯片共享同一地址空间，同时被选中（并行而非串行）**

```
            地址总线（log₂m 位）
               │        │
        ┌──────┴──┐ ┌───┴─────┐
        │ 芯片1    │ │ 芯片2    │ ← 地址线、片选线全部并联
        │ m×b₁    │ │ m×b₂    │
        └──┬──────┘ └──┬──────┘
        D0~b₁-1     Db₁~B-1       ← 数据线各接数据总线的不同位
           └────┬───────┘
            数据总线（B位）
```

- **地址分配**：不分段！同一地址同时对应各芯片的不同位段，拼成一个完整字
- **连线**：地址线并联、**片选并联**、数据线分接总线高低位；前提：数据总线宽度 = 扩展后字长

> [!example] 位扩展示例
> 用 16K × 4 位的芯片组成 16K × 8 位的存储器
> - 需要 2 片芯片
> - 地址线共用，数据线分别连接高4位和低4位

> [!important] 位扩展是并行：1个周期读完一个字
> 8片 8K×8 组成 8K×64：读第 i 个字时，地址（13位）同时到达8片，片选并联**8片同时选中**，各出8位，在64位总线上拼成完整字——**一次访存、1个存取周期完成**
> 只有"数据总线仅8位宽"时才被迫分8次搬，但那应该做字扩展（变成64K×8）而不是位扩展
> **口诀：位扩展把字加宽（并行拼位，1次读出），字扩展把字数加长（分段接力，n次读出）**

#### 字扩展（增加字数）

**规则：地址空间按芯片容量分段，每片占一段连续地址，片选互斥（轮流值班）**

```
   地址总线
    │高位          │低位（并联到每片地址引脚）
    ▼               ▼
 ┌───────┐    ┌─────┬─────┬─────┬─────┐
 │ n-m   │───►│芯片1│芯片2│芯片3│芯片4│ ← 片选互斥：译码器每次只激活一根
 │ 译码器 │    │     │     │     │     │
 └───────┘    └──┬──┴──┬──┴──┬──┴──┬──┘
                └─────数据总线─────┘ ← 数据线全部并联（三态门隔离，见3.2.3）
```

- **地址分配**：芯片 i 的范围 = [i×m, (i+1)×m)；片内地址位数 = log₂m，所有芯片相同
- **连线**：低位地址并联、**高位地址进译码器产生片选**、数据线并联

> [!example] 字扩展示例（4片 16K×8 组成 64K×8）
> 地址16位 = 高2位（片选）+ 低14位（片内，log₂16K），2-4译码器：
>
> | 片选（高2位） | 芯片 | 地址范围 |
> |:---:|:---:|:---|
> | 00 | 芯片1 | 0000H ~ 3FFFH |
> | 01 | 芯片2 | 4000H ~ 7FFFH |
> | 10 | 芯片3 | 8000H ~ BFFFH |
> | 11 | 芯片4 | C000H ~ FFFFH |

> [!important] 辨析：字扩展 ≡ 高位交叉编址（教材原话级考点）
> "高位交叉的多模块结构，本质上与存储器的字扩展是一样的"（见3.2.5）
> - 地址划分完全相同：高位选模块/芯片、低位块内寻址；连续地址集中在同一块，串行接力、带宽不提高
> - 区别只在视角：字扩展谈"**怎么造**"（容量问题）；高位交叉谈"多体并行"（性能问题，作为低位交叉的反面参照）
> - 判断题"高位交叉编址能提高带宽"——**错**；读连续n字：高位交叉 = n×T，低位交叉 = T+(n-1)r

#### 字位同时扩展

**先位扩展成"组"，再字扩展成多组**，地址分配分两级：高位选组（译码器），低位组内地址（组内芯片共用）

> [!example] 经典计算题：用 16K×4 芯片组成 128K×8
> 1. **算数**：总数 = (128K×8)/(16K×4) = 16片；每组 = 8/4 = 2片（位扩）；组数 = 128K/16K = 8组（字扩）
> 2. **地址分配**：总地址17位（log₂128K）= 高3位组选（3-8译码器）+ 低14位组内地址（同组2片共用）
> 3. **连线**：组内按位扩展（地址/片选并联、数据分接D0~3与D4~7）；组间按字扩展（数据并联、片选来自译码器互斥）
>
> | 组选（高3位） | 地址范围 | 组内构成 |
> |:---:|:---|:---|
> | 000 | 00000H~03FFFH | 2片：一片供D0~D3，一片供D4~D7 |
> | 001 | 04000H~07FFFH | 同上 |
> | … | 每组跨 16K（4000H） | … |
> | 111 | 1C000H~1FFFFFH | 同上 |

#### 三种扩展对比总结

| | 位扩展 | 字扩展 | 字位同时 |
|:---|:---|:---|:---|
| 地址空间 | 全部芯片**共享** | 按芯片字数**分段** | 按**组**分段，组内共享 |
| 片选 | **并联**（同时选中） | 译码器输出，**互斥** | 组间互斥、组内并联 |
| 地址线 | 全部并联 | 低位并联 + 高位进译码器 | 同左（高位=组选） |
| 数据线 | 各接总线**不同位** | 全部**并联** | 组内分位、组间并联 |
| 读一个目标字 | 1个周期（并行） | 1个周期（但连续n字要n次） | 同左 |

#### 解题步骤模板

1. 芯片总数 = (M×B)/(m×b)，定出组数与每组片数
2. 地址位数：总地址 log₂M；片内地址 log₂m；组选 log₂(M/m)
3. 各片/各组地址范围 = 块号 × 块容量 起
4. 译码器规格：组选位数 → 2^n-m 译码器（如高3位→3-8）
5. 连线：组内位扩展接法，组间字扩展接法

### 3.2.5 多模块存储器（顺序编址与交叉编址）

**动机**：CPU 远快于主存（差数百倍，见[[专题01——周期|专题01]]），除 Cache 外另一条路是让多个存储模块并行工作，提高主存带宽。

| 方式 | 解决什么 | 结构 |
|:-----|:-----|:-----|
| 单体多字 | 字长太短 | 一个模块一次并行读出多个字（加宽位线） |
| **多模块** | 速度慢/带宽小 | 多个独立模块，两种编址方式 ↓ |

#### 顺序编址（高位交叉）

- **地址高位 = 模块号**，低位 = 模块内地址；连续地址集中在同一模块（地址结构与 3.2.4 字扩展完全相同，教材：高位交叉多模块本质上就是字扩展）
- 连续访问只能串行接力，**带宽不提高**；本质是大内存切块，主要意义是**方便扩容**
- 模块无需独立 MAR/MDR（仅片选区分）

#### 交叉编址（低位交叉）

- **地址低位 = 模块号**，模块号 = 地址 mod m（m 为模块数）；连续地址轮流落在不同模块
- **各模块有独立的 MAR、MDR 和读写控制电路**（重要考点，顺序编址不需要）

#### 两种启动方式与时间计算

设存储周期 T，总线传送周期 r，m 体交叉，读连续 n 字：

**流水线启动（主流）**：每隔 r 启动下一个模块

```
体1: 字0 ├─T─┤      字4 ├─T─┤    （t=0, m·r, …）
体2:    字1 ├─T─┤     字5 ├─T─┤（t=r, m·r+r, …）
体3:       字2 ├─T─┤   …
体4:          字3 ├─T─┤ …
```

- **无冲突条件：m·r ≥ T**；每 r 出一个字
- **读 n 字时间 = T + (n-1)·r**（n 是字数，不是批数！）

**同时启动（并行启动）**：m 体同时启动，完成后总线分时传送

- **无冲突条件：T ≥ m·r**；每满批耗时 **T + m·r**
- 分批：⌈n/m⌉ 批；**末批不满时要用实际字数修正**（末批 = T + 字数×r）

> [!example] 计算例题（25字节、四体交叉、T=200ns、r=50ns）
> 字长 1B，字节 i 存于体 (i mod 4)+1：
>
> | 体 | 存的字节 | 个数 |
> |:--:|:---|:--:|
> | 一号 | 0,4,8,12,16,20,24 | 7 |
> | 二号 | 1,5,9,13,17,21 | 6 |
> | 三号 | 2,6,10,14,18,22 | 6 |
> | 四号 | 3,7,11,15,19,23 | 6 |
>
> 读完 25 字节（地址 0~24）：
>
> | 方式 | 公式 | 结果 | 带宽 |
> |:---|:---|:---:|:---:|
> | 顺序编址（对照） | 25 × T | 5000 ns | 5.0 MB/s |
> | 同时启动 | 6×(T+4r) + (T+1×r)（末批仅1字） | 2650 ns | 9.4 MB/s |
> | 流水线启动 | T + 24r | **1400 ns** | **17.9 MB/s** |
>
> 加速比 = 5000/1400 ≈ 3.6 倍（理想上限 m=4 倍，未到因流水线建立时间与末批不满）

> [!important] 判别技巧与易错点
> - 口诀：**高位交叉是顺序，低位交叉是交叉**；地址落在哪体：低位交叉 = 地址 mod m，高位交叉 = 地址 div 体容量
> - 交叉编址模块**必须有独立 MAR/MDR**，顺序编址不需要——选择题最爱考
> - T ≠ m·r 时流水线会"撞车"（体未空闲就被再启动），需插等待拍，实际时间 > T+(n-1)r
> - 末批不满（如 25 = 6×4+1）要单独计算末批时间
> - 实机呼应：DDR5 的子通道 + bank 交错即流水线启动的现实版

### 3.2.6 外存储器：磁盘与 SSD

#### 磁盘的层次结构

```
磁盘驱动器
 ├─ 盘片（Platter）× N 片        ← 刚性铝/玻璃基板，叠装在同一主轴上
 │   └─ 盘面（Surface）× 2N 个    ← 每片上下两面；每面配一个磁头
 │       └─ 磁道（Track）          ← 盘面上的同心圆，由外向内编号 0,1,2…
 │           └─ 扇区（Sector）     ← 磁道切成的弧段，最小物理读写单位
 ├─ 主轴+电机：带动盘片同速旋转（5400/7200 RPM）
 ├─ 磁头臂：所有磁头固定在一起，只能整体沿半径移动
 └─ 柱面（Cylinder）：所有盘面上编号相同的磁道围成的圆柱面（逻辑概念）
```

- **盘面数 = 磁头数**：磁头号就是盘面号
- 扇区是最小物理读写单位；OS 层的盘块由若干扇区组成（分配单位）
- 现代磁盘每磁道扇区数不等（外圈多，ZBR）；**408 一律按相同处理**

#### 柱面的本质与作用

**本质**：所有磁头固定在同一磁头臂上只能整体移动，磁头臂停在某处时，各盘面磁头正对的磁道编号必然相同——这些磁道的集合就是柱面。柱面 = **磁头臂不动就能访问到的全部范围**

四大作用：

1. **消灭寻道**：换盘面只切磁头（电子开关，几乎不耗时），连续数据放同柱面 → 寻道 1 次
2. **空间分配单位**：OS 先装满一个柱面再移相邻柱面
3. **CHS 地址第一级**：柱面号对应唯一机械动作（移臂），决定耗时量级
4. **调度算法的优化对象**：SSTF/SCAN 等优化的"寻道距离"就是柱面号之差

#### 磁盘地址与访问时间

$$磁盘地址 = (柱面号, 磁头号, 扇区号)$$

| 步骤 | 动作 | 耗时 |
|:---|:---|:---|
| ① 寻道 | 磁头臂移到目标柱面 | 寻道时间（ms级，最大头） |
| ② 选面 | 电子切换磁头 | ≈ 0 |
| ③ 等扇区 | 旋转到目标扇区在磁头下 | 平均 = 半圈时间 + 传输时间 |

$$磁盘容量 = 柱面数 \times 磁头数 \times 每磁道扇区数 \times 每扇区字节数$$

> [!example] 计算例题
> 4 个盘片、1000 柱面、每磁道 63 扇区、每扇区 512B，转速 7200 RPM：
> 盘面数=磁头数=8；容量 = 1000×8×63×512B ≈ 258 MB；转一圈 = 60/7200 = 8.33ms → 平均旋转延迟 4.17ms

磁盘属于**直接存取存储器（DAM）**（见3.1.3）：先直接定位柱面/盘面，再顺序等待扇区。磁盘调度算法详见 [[磁盘结构与调度算法|操作系统·磁盘结构与调度算法]]

#### 存取时间计算：条件映射与模板

**条件对号入座表**（所有已知条件都转成这三段）：

| 已知条件 | 转换成什么 |
|:---|:---|
| 转速 n（RPM） | 转一圈 = **60/n 秒**（7200 RPM → 8.33ms）；**平均旋转延迟 = 半圈 = 30/n** |
| 每磁道扇区数 S | 读一个扇区传输 = 一圈时间 ÷ S（磁盘匀速旋转，传输时间本质是"转了多少圈"） |
| 每扇区字节数 + 数据量 | 扇区数 = 数据量 ÷ 扇区大小 |
| 寻道时间（或每移一道 x ms） | 直接加；跨 k 道时按题意加 (k−1)×x 或平均值 |

**三个计算模板**：

| 场景 | 公式 |
|:---|:---|
| 读一个扇区 | T = 寻道 + ½·(60/n) + (1/S)·(60/n) |
| 读一个完整磁道 | T = 寻道 + ½·(60/n) + (60/n) |
| 读连续 n 个扇区（跨道） | T = 寻道 + ½·(60/n) + (n/S)·(60/n) + 跨道数×每道寻道 |

> [!example] 例题（DMA扇区传送）
> 7200 RPM、每磁道 200 扇区、每扇区 512B，忽略寻道：
> 转一圈 = 60/7200 = 8.33ms；平均旋转延迟 = 4.17ms；一扇区传输 = 8.33/200 = 0.042ms
> 读一扇区 ≈ 4.17 + 0.042 ≈ **4.21ms**
> 传输 512B 仅 0.042ms ≪ 中断开销 → 磁盘与主存间适合 **DMA** 而非中断方式

> [!example] 跨磁道例题
> 同上，另知平均寻道 5ms。读 4KB 连续文件（从磁道中间开始，每道 200 扇区）：
> 4KB ÷ 512B = 8 个扇区，本道装得下，不跨道：T = 5 + 4.17 + 8×0.042 ≈ **9.5ms**
> 若 1MB（2048扇区，跨 11 道）：T = 5 + 4.17 + (2048/200)×8.33 + 10×5 ≈ **144.6ms**（跨道是否计寻道、计几次以题干为准）

> [!important] 易错点与口诀
> - **平均旋转延迟 = 半圈**，不是一圈；"最大"才是一圈
> - 传输时间 = 圈时间 × 圈数（圈数由数据量/每道扇区数定），**不要拿数据量直接除转速**
> - RPM→时间：60/n，先统一成 ms 再算；"寻道时间"是平均值还是每道耗时，用法不同，先看清
> - 口诀：**转速定圈时，半圈是等待；扇区定传输，跨道加寻道**

#### 最小读写单位：编址单位 ≠ 物理读写单位

"按字节/字编址"（见3.2.3）只决定**地址粒度**；硬件一次实际搬运以**物理单位**为下限：

| 存储器 | 编址粒度（逻辑） | 物理最小读写单位 | 访问方式 |
|:---|:---|:---|:---|
| 主存 DRAM | 字节/字 | **存储字**（×突发至64B行） | 随机（读整字挑字节，见3.2.3） |
| Cache↔主存 | — | **块/行**（64B） | 以块交换 |
| HDD | 盘块 | **扇区**（512B/4KB） | 直接存取（DAM） |
| SSD | 盘块 | **页**（读/写）、**块**（擦） | 随机读、准随机写 |

- CPU 要 1 字节：主存读出整个字挑出该字节；OS 要 1 字节：磁盘读出整个扇区
- 磁盘是**块设备**，CPU 不能给磁盘一个字节地址直接访问

#### SSD：页读写、块擦除

| 操作 | 最小单位 | 典型大小 |
|:---|:---|:---:|
| 读 | 页 | 4~16 KB |
| 写 | 页（**写前必须先擦**） | 4~16 KB |
| 擦除 | **块**（=128~512页） | 几百KB~几MB |

物理原因：写是把电荷注入浮栅（位只能 1→0），擦是释放电荷（整块回到 1）→ 覆盖写 = 擦+写

**原地改写（教科书模型）**：读整块 → 擦整块 → 改一页 → **写回整块**（擦会毁掉块内所有页，其他页必须一起回写）

**异地写+GC（真实 SSD 的 FTL）**：新数据直接写到空闲页，旧页标记无效；擦除推迟到垃圾回收——把有效页搬到新块再擦旧块。产生**写放大**，需 FTL 映射与**磨损均衡**（闪存擦写次数有限：SLC≈10万，TLC≈1千）

> [!important] 易错点
> - 盘面数 = 磁头数（不是盘片数，每片2面）；柱面 = 各盘面同号磁道的集合
> - 换柱面要移臂（慢）、换盘面只切磁头（快）、找扇区靠旋转（中）
> - 编址单位 ≠ 物理读写单位：地址按字节，主存搬存储字、HDD搬扇区、SSD搬页
> - SSD 不能原地覆盖：写只能 1→0，擦整块才能归 1；擦以块为单位而非页

## 3.3 Cache（高速缓存）

### 3.3.1 Cache的工作原理

- Cache位于CPU和主存之间，用于缓解速度不匹配问题
- **命中率**：CPU访问Cache成功的次数 / 总访问次数
- **缺失率（未命中率）**：1 - 命中率

#### Cache的性能指标

$$t_a = h \times t_c + (1 - h) \times t_m$$

- $t_a$：平均访问时间
- $h$：命中率
- $t_c$：Cache访问时间
- $t_m$：主存访问时间

$$e = \frac{t_c}{t_a} = \frac{t_c}{h \times t_c + (1-h) \times t_m}$$

- $e$：Cache的效率

> [!example] Cache性能计算示例
> 设 t_c = 1ns，t_m = 100ns，h = 0.9
> - 平均访问时间 = 0.9 × 1 + 0.1 × 100 = 0.9 + 10 = 10.9 ns
> - 效率 = 1 / 10.9 ≈ 0.092 = 9.2%

> [!important] 辨析题："CPU只能与Cache直接交换信息，与主存交换也要经过Cache"——错
> 1. Cache、主存、I/O设备都挂在系统总线上，CPU可直接对任一者发地址和读写命令；某些不可缓存区域（如I/O映射内存）的访问绕过Cache直达主存
> 2. **Cache对CPU透明**：CPU只"发地址、等数据"，不知道Cache存在；访存请求被Cache控制器截获，命中则Cache应答，未命中则**转发**给主存——逻辑上CPU始终直接访问主存，Cache只是"经手转发"而非必经中介（见3.1.4）
> 3. 反例：DMA方式下主存与I/O设备成块交换数据，连CPU都不经过，更不经Cache

### 3.3.2 Cache映射方式

#### 地址划分

主存地址分为两部分：
- **标记（Tag）**：用于判断是否命中
- **块内地址（Block Offset）**：用于定位块内的具体单元

#### 直接映射（Direct Mapping）

- 主存中每一块只能映射到Cache的**固定行**中
- 映射关系：Cache行号 = 主存块号 mod Cache行数

```
主存地址格式：
| 标记Tag | Cache行号Index | 块内地址Offset |
```

- **优点**：实现简单，速度快
- **缺点**：冲突率高，空间利用率低

> [!example] 直接映射地址计算示例
> 设主存容量 256KB，Cache容量 16KB，块大小 64B
> - 主存地址位数 = log2(256K) = 18位
> - 块内地址 = log2(64) = 6位
> - Cache行数 = 16KB / 64B = 256行
> - Cache行号 = log2(256) = 8位
> - 标记位 = 18 - 8 - 6 = 4位
>
> 地址格式：`| 标记(4位) | 行号(8位) | 块内地址(6位) |`
>
> 主存地址 0x00A3C 对应：
> - 二进制：00 0000 1010 0011 1100
> - 标记 = 0000 = 0
> - 行号 = 00101000 = 40
> - 块内地址 = 111100 = 60

#### 全相联映射（Fully Associative）

- 主存中每一块可以映射到Cache的**任意行**
- 不需要Index字段

```
主存地址格式：
| 标记Tag | 块内地址Offset |
```

- **优点**：冲突率最低，空间利用率最高
- **缺点**：实现复杂，需要与所有行同时比较，速度慢

#### 组相联映射（Set Associative）

- Cache分为若干组，每组有若干行
- 主存块先映射到特定组，再映射到组内任意行
- 映射关系：组号 = 主存块号 mod 组数

```
主存地址格式：
| 标记Tag | 组号Index | 块内地址Offset |
```

- n路组相联：每组有n行
- 直接映射 = 1路组相联
- 全相联映射 = Cache行数路组相联

> [!example] 组相联映射地址计算示例
> 设Cache容量 64KB，块大小 64B，4路组相联
> - Cache总行数 = 64KB / 64B = 1024行
> - 组数 = 1024 / 4 = 256组
> - 组号位数 = log2(256) = 8位
> - 块内地址 = log2(64) = 6位
> - 标记位 = 主存地址位 - 8 - 6
>
> 地址格式：`| 标记Tag | 组号(8位) | 块内地址(6位) |`

#### 三种映射方式对比

| 特征 | 直接映射 | 全相联映射 | 组相联映射 |
|:-----|:--------:|:----------:|:----------:|
| 地址格式 | Tag + Index + Offset | Tag + Offset | Tag + Index + Offset |
| 映射关系 | 固定行 | 任意行 | 固定组，组内任意行 |
| 冲突率 | 最高 | 最低 | 中等 |
| 硬件成本 | 最低 | 最高 | 中等 |
| 查找速度 | 最快 | 最慢 | 中等 |
| 空间利用率 | 最低 | 最高 | 中等 |

### 3.3.3 Cache替换算法

当Cache满且需要装入新块时，需要选择替换哪一行。

| 算法 | 说明 | 优缺点 |
|:-----|:-----|:-------|
| 随机替换（RAND） | 随机选择一行替换 | 实现简单，但性能不稳定 |
| 先进先出（FIFO） | 替换最早调入的行 | 实现简单，但可能产生Belady异常 |
| 最近最少使用（LRU） | 替换最近最久未被访问的行 | 性能好，但实现复杂 |
| 最不经常使用（LFU） | 替换访问次数最少的行 | 考虑长期访问频率 |

> [!important] 考点
> - LRU是考试中最常考的替换算法
> - LRU实现方法：为每行设置计数器，每次访问时更新
> - 注意LRU和LFU的区别：LRU看时间，LFU看次数

### 3.3.4 Cache写策略

#### 写命中（Write Hit）

| 策略 | 说明 | 优缺点 |
|:-----|:-----|:-------|
| 全写法（Write Through） | 同时写入Cache和主存 | 一致性好，但写速度慢 |
| 写回法（Write Back） | 只写Cache，替换时才写回主存 | 速度快，但一致性问题 |

#### 写不命中（Write Miss）

| 策略 | 说明 |
|:-----|:-----|
| 写分配法（Write Allocate） | 先将主存块调入Cache，再写入Cache |
| 非写分配法（No Write Allocate） | 直接写入主存，不调入Cache |

> [!note] 常见组合
> - 写回法 + 写分配法（常用）
> - 全写法 + 非写分配法（常用）

## 3.4 虚拟存储器

### 3.4.1 基本概念

- 虚拟存储器将主存和辅存统一编址，为用户提供比实际主存大得多的虚拟地址空间
- 用户编程使用**虚拟地址（逻辑地址）**，实际访问使用**物理地址（实地址）**
- 虚拟地址到物理地址的转换由**MMU（内存管理单元）**完成

### 3.4.2 页式虚拟存储器

- 将虚拟地址空间和物理地址空间都划分为固定大小的**页**
- **页表**：记录虚拟页号到物理页号的映射关系

```
虚拟地址：| 虚拟页号 | 页内偏移 |
物理地址：| 物理页号 | 页内偏移 |
```

#### TLB（Translation Lookaside Buffer，快表）

- TLB是一种特殊的Cache，用于缓存最近使用的页表项
- **TLB命中**：直接从TLB获取物理页号，无需访问主存中的页表
- **TLB未命中**：访问主存中的页表，获取物理页号，同时更新TLB

#### 访问过程

```
虚拟地址 → 查TLB
  ├─ TLB命中 → 获取物理页号 → 形成物理地址 → 访问Cache/主存
  └─ TLB未命中 → 查页表（在主存中）
       ├─ 页表命中 → 获取物理页号 → 更新TLB → 访问Cache/主存
       └─ 页表未命中（缺页） → 从辅存调入页面 → 更新页表和TLB → 重新访问
```

> [!example] TLB和Cache联合访问计算
> 设 TLB命中率 = 0.9，Cache命中率 = 0.95
> TLB访问时间 = 1ns，Cache访问时间 = 2ns，主存访问时间 = 100ns
>
> **情况1：TLB命中 + Cache命中** = 1 + 2 = 3ns（概率 0.9 × 0.95 = 0.855）
> **情况2：TLB命中 + Cache未命中** = 1 + 2 + 100 = 103ns（概率 0.9 × 0.05 = 0.045）
> **情况3：TLB未命中 + Cache命中** = 1 + 100 + 2 = 103ns（概率 0.1 × 0.95 = 0.095）
> **情况4：TLB未命中 + Cache未命中** = 1 + 100 + 2 + 100 = 203ns（概率 0.1 × 0.05 = 0.005）
>
> 平均访问时间 = 3 × 0.855 + 103 × 0.045 + 103 × 0.095 + 203 × 0.005
> = 2.565 + 4.635 + 9.785 + 1.015 = **18.0 ns**

### 3.4.3 页表结构

| 页表项字段 | 说明 |
|:----------:|:-----|
| 物理页号（页框号） | 虚拟页对应的物理页号 |
| 有效位 | 该页是否在主存中 |
| 脏位（修改位） | 该页是否被修改过 |
| 访问位 | 该页是否被访问过 |
| 保护位 | 读/写/执行权限 |

## 3.5 考点总结

### 高频考点

1. **SRAM与DRAM对比**：存储元件、刷新、速度、用途；SDRAM同步化与DDR双沿传输（见3.2.1）
2. **DRAM刷新与引脚复用**：三种刷新方式的死区/间隔计算、刷新计数器供址、RAS̄/CAS̄行列复用（见3.2.2）
3. **Cache映射方式**：直接映射、全相联映射、组相联映射的地址划分和计算（必考）
4. **Cache替换算法**：LRU算法的执行过程
5. **Cache写策略**：写命中（全写法/写回法）、写不命中（写分配/非写分配）
6. **虚拟存储器**：TLB工作原理、TLB+Cache联合访问计算（见3.4.2）
7. **相联存储器（CAM）**：按内容寻址的结构与优缺点、与相联映射的辨析（见3.1.4）
8. **存储器芯片结构**：五大部件、字线/位线、单/双译码、读取时序与存取周期；按字节/按字编址的地址数与地址线计算（见3.2.3）
9. **多模块存储器**：高位交叉（顺序）与低位交叉（交叉）编址、独立MAR/MDR、流水线/同时启动的时间计算（见3.2.5）
10. **存储器的扩展**：位/字/字位同时扩展的地址分配、连线方式（片选并联vs互斥）、地址范围与译码器计算（见3.2.4）
11. **外存储器**：磁盘层次（盘面=磁头、柱面）、CHS寻址、**存取时间三段计算模板**（条件映射表：转速→圈时/半圈，扇区数→传输时间）、最小读写单位（扇区/页/块）、SSD写前擦除与异地写+GC（见3.2.6）

### 易错点

- Cache行号 = 主存块号 mod Cache行数（直接映射）
- 组相联映射中：组号 = 主存块号 mod 组数
- DRAM刷新以行为单位，不是以位为单位；刷新地址由**刷新计数器**产生而非CPU，只用行地址（RAS-only）、与列地址无关，对CPU透明（见3.2.2）
- 写回法只在替换时写回主存，全写法每次写都同时写主存
- TLB未命中时需要访问主存中的页表，此时多一次主存访问（见3.4.2）
- 相联存储器是按内容寻址的器件（CAM），相联映射是Cache映射策略，后者靠前者实现，不要混为一谈（见3.1.4）
- **Cache对CPU透明**："CPU只能和Cache交换、访存必过Cache"是错的；未命中时请求转发给主存，DMA传输不经Cache
- **电平即 01，MDR 只做锁存不做"转化"**；位线信号微弱须经灵敏放大器（DRAM放大兼回写恢复）（见3.2.3）
- 字线数=字数、位线数=字长只在逻辑视角成立；DRAM地址引脚行列复用，≠ log₂字数（见3.2.3）
- 读连续字节数组的周期数 = ⌈字节数/字长⌉，未对齐可能多一次；译码方式不影响存取周期（见3.2.3）
- **SRAM ≠ SDRAM**：前者触发器不刷新（Cache），后者同步化DRAM仍靠电容、仍需刷新（主存）（见3.2.1）
- **位扩展是并行**：片选并联、8片同时输出拼字，读一个字只要1个周期；字扩展片选互斥轮流值班，读连续n字要n次（见3.2.4）
- 字扩展 ≡ 高位交叉编址，"高位交叉能提高带宽"是错的；地址段大小由芯片**字数**决定，与位数无关（见3.2.4）
- 容量计算先算**总位数**再除以编址单位：如 4×512K×8 = 2^24 位，按字节编址是 2^21 个地址而不是 2^24 个（见3.2.3）
- 磁盘容量 = 柱面×磁头×每道扇区×扇区字节，用**磁头数（=盘面数）**而不是盘片数；平均旋转延迟 = **半圈**时间，传输时间 = 圈时间×圈数，勿拿数据量直接除转速（见3.2.6）

### 常用公式速查

| 公式 | 说明 |
|:-----|:-----|
| t_a = h × t_c + (1-h) × t_m | 平均访问时间 |
| e = t_c / t_a | Cache效率 |
| Cache行数 = Cache容量 / 块大小 | 行数计算 |
| 标记位 = 主存地址位 - Index位 - Offset位 | 地址划分 |
| 交叉编址读n字 = T + (n-1)·r | 条件 m·r ≥ T，n为字数（见3.2.5） |
| 磁盘存取时间 = 寻道 + 半圈·(60/转速) + (扇区数/每道扇区)·(60/转速) | 跨道另加寻道（见3.2.6） |
