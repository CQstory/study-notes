# 第二章——栈和队列

## 一、栈

### 1.1 栈的定义

栈（Stack）是只允许在**一端**进行插入或删除操作的线性表。栈是**后进先出**（Last In First Out, **LIFO**）的线性表。

- **栈顶（Top）**：允许进行插入和删除的一端
- **栈底（Bottom）**：固定不动的一端
- **空栈**：不含任何元素的栈

栈的基本操作：
| 操作 | 功能描述 |
|------|---------|
| `InitStack(&S)` | 初始化一个空栈 |
| `StackEmpty(S)` | 判断栈是否为空 |
| `Push(&S, x)` | 进栈（压栈），将 x 放入栈顶 |
| `Pop(&S, &x)` | 出栈（弹栈），弹出栈顶元素并用 x 返回 |
| `GetTop(S, &x)` | 读栈顶元素，但不弹出 |
| `DestroyStack(&S)` | 销毁栈 |

### 1.2 顺序栈

顺序栈用数组实现，栈顶指针 `top` 指向栈顶元素。

```c
#define MaxSize 100
typedef struct {
    ElemType data[MaxSize];
    int top;  // 栈顶指针
} SqStack;
```

**初始化**：
```c
void InitStack(SqStack *S) {
    S->top = -1;  // 栈顶指针初始化为 -1
}
```

**判断栈空**：
```c
bool StackEmpty(SqStack S) {
    return S.top == -1;
}
```

**进栈**：
```c
bool Push(SqStack *S, ElemType x) {
    if (S->top == MaxSize - 1) return false;  // 栈满
    S->data[++S->top] = x;  // 先 top++，再入栈
    return true;
}
```

**出栈**：
```c
bool Pop(SqStack *S, ElemType *x) {
    if (S->top == -1) return false;  // 栈空
    *x = S->data[S->top--];  // 先出栈，再 top--
    return true;
}
```

> **注意**：`top` 的初始值有两种约定：
> - `top = -1`：指向栈顶元素，栈空条件为 `top == -1`，栈满条件为 `top == MaxSize - 1`
> - `top = 0`：指向栈顶元素的下一个位置，栈空条件为 `top == 0`，栈满条件为 `top == MaxSize`
>
> 408 考研中常用 `top = -1` 的约定。

### 1.3 共享栈

两个栈共享同一片存储空间，栈底分别设在数组的两端。

```c
typedef struct {
    ElemType data[MaxSize];
    int top0;  // 栈 0 的栈顶指针，从 -1 开始向右增长
    int top1;  // 栈 1 的栈顶指针，从 MaxSize 开始向左增长
} ShStack;
```

- 栈满条件：`top0 + 1 == top1`
- 适用于两个栈空间需求有相反关系的情况

### 1.4 链栈

链栈用单链表实现，所有操作都在**表头**进行（即链栈没有头节点，或者头节点就是栈顶）。

```c
typedef struct LinkNode {
    ElemType data;
    struct LinkNode *next;
} LinkNode, *LiStack;
```

- 进栈：头插法
- 出栈：删除第一个节点
- 链栈没有栈满的问题（除非内存耗尽）
- 栈空条件：`L == NULL`（不带头节点）或 `L->next == NULL`（带头节点）

### 1.5 栈的应用

#### （1）括号匹配

算法思想：从左到右扫描表达式，遇到左括号入栈，遇到右括号则检查栈顶是否匹配。

```c
bool BracketCheck(char str[], int n) {
    SqStack S;
    InitStack(&S);
    for (int i = 0; i < n; i++) {
        if (str[i] == '(' || str[i] == '[' || str[i] == '{')
            Push(&S, str[i]);
        else if (str[i] == ')' || str[i] == ']' || str[i] == '}') {
            if (StackEmpty(S)) return false;  // 右括号多于左括号
            char top;
            Pop(&S, &top);
            if (str[i] == ')' && top != '(') return false;
            if (str[i] == ']' && top != '[') return false;
            if (str[i] == '}' && top != '{') return false;
        }
    }
    return StackEmpty(S);  // 栈空说明全部匹配
}
```

**示例**：`(a + b) * [c - {d / e}]`
- `(` 入栈 → `[` 入栈 → `{` 入栈
- `}` 匹配 `{` 出栈 → `]` 匹配 `[` 出栈 → `)` 匹配 `(` 出栈
- 栈空，匹配成功

#### （2）表达式求值——中缀转后缀

**中缀表达式**：运算符在两个操作数之间，如 `a + b * c`
**后缀表达式（逆波兰表达式）**：运算符在两个操作数之后，如 `a b c * +`

**中缀转后缀的规则**：
1. 从左到右扫描中缀表达式
2. 遇到**操作数**：直接输出
3. 遇到**运算符**：
   - 若栈为空或栈顶为 `(`，直接入栈
   - 若当前运算符优先级**大于**栈顶运算符优先级，入栈
   - 若当前运算符优先级**小于等于**栈顶运算符优先级，弹出栈顶运算符并输出，重复比较
4. 遇到 `(`：入栈
5. 遇到 `)`：弹出栈中运算符并输出，直到遇到 `(`
6. 扫描完毕后，将栈中剩余运算符全部弹出

**示例**：将 `a + b * c - d` 转为后缀表达式

| 步骤 | 当前字符 | 操作 | 栈 | 输出 |
|------|---------|------|----|------|
| 1 | a | 输出 | 空 | a |
| 2 | + | 入栈 | + | a |
| 3 | b | 输出 | + | a b |
| 4 | * | 优先级 > +，入栈 | + * | a b |
| 5 | c | 输出 | + * | a b c |
| 6 | - | 优先级 < *，弹出 *；优先级 = +，弹出 +；入栈 - | - | a b c * + |
| 7 | d | 输出 | - | a b c * + d |
| 8 | 结束 | 弹出全部 | 空 | a b c * + d - |

**结果**：`a b c * + d -`

**后缀表达式求值**（用栈）：
1. 从左到右扫描后缀表达式
2. 遇到操作数入栈
3. 遇到运算符，弹出两个操作数，计算后将结果入栈
4. 最终栈中只剩一个元素，即为结果

#### （3）递归

函数调用时，系统使用**函数调用栈**（工作栈）来保存：
- 返回地址
- 局部变量
- 参数传递

递归的本质就是系统自动使用栈来保存每一层递归的状态。

**示例**：阶乘 `n!` 的递归过程
```
fact(5)
→ fact(4)
  → fact(3)
    → fact(2)
      → fact(1)  // 递归边界
      ← 1
    ← 2 * 1 = 2
  ← 3 * 2 = 6
← 4 * 6 = 24
← 5 * 24 = 120
```

> **考点**：递归的深度等于栈的最大深度。递归可以转化为非递归（使用显式栈）。

## 二、队列

### 2.1 队列的定义

队列（Queue）是只允许在**一端插入**、在**另一端删除**的线性表。队列是**先进先出**（First In First Out, **FIFO**）的线性表。

- **队头（Front）**：允许删除的一端
- **队尾（Rear）**：允许插入的一端

队列的基本操作：
| 操作 | 功能描述 |
|------|---------|
| `InitQueue(&Q)` | 初始化一个空队列 |
| `QueueEmpty(Q)` | 判断队列是否为空 |
| `EnQueue(&Q, x)` | 入队，将 x 放入队尾 |
| `DeQueue(&Q, &x)` | 出队，删除队头元素并用 x 返回 |
| `GetHead(Q, &x)` | 读队头元素，但不删除 |

### 2.2 顺序队列与循环队列

#### 顺序队列的问题

用数组实现队列时，出队操作只是将队头指针后移，前面的空间无法再利用，产生**假溢出**。

#### 循环队列

将队列的存储空间在逻辑上看作一个**环**，通过取模运算实现。

```c
#define MaxSize 100
typedef struct {
    ElemType data[MaxSize];
    int front, rear;  // 队头指针和队尾指针
} SqQueue;
```

**约定**：
- `front` 指向队头元素
- `rear` 指向队尾元素的**下一个位置**

**初始化**：
```c
void InitQueue(SqQueue *Q) {
    Q->front = Q->rear = 0;
}
```

**判断队空**：
```c
bool QueueEmpty(SqQueue Q) {
    return Q.front == Q.rear;
}
```

**入队**：
```c
bool EnQueue(SqQueue *Q, ElemType x) {
    if ((Q->rear + 1) % MaxSize == Q->front) return false;  // 队满
    Q->data[Q->rear] = x;
    Q->rear = (Q->rear + 1) % MaxSize;
    return true;
}
```

**出队**：
```c
bool DeQueue(SqQueue *Q, ElemType *x) {
    if (Q->front == Q->rear) return false;  // 队空
    *x = Q->data[Q->front];
    Q->front = (Q->front + 1) % MaxSize;
    return true;
}
```

#### 队空与队满的判断

由于队空和队满时都有 `front == rear`，需要区分：

| 方法 | 队空条件 | 队满条件 | 说明 |
|------|---------|---------|------|
| **牺牲一个存储单元** | `front == rear` | `(rear + 1) % MaxSize == front` | 最常用方法，实际可用容量为 MaxSize - 1 |
| **设置标志位** | `front == rear && tag == 0` | `front == rear && tag == 1` | tag 表示最近一次操作是删除(0)还是插入(1) |
| **记录元素个数** | `size == 0` | `size == MaxSize` | 增加一个 size 变量 |

> **408 考研重点**：牺牲一个存储单元的方法是最常考的。

**队列长度计算**：
$$length = (rear - front + MaxSize) \% MaxSize$$

### 2.3 链式队列

链式队列用单链表实现，队头在链头，队尾在链尾。

```c
typedef struct LinkNode {
    ElemType data;
    struct LinkNode *next;
} LinkNode;

typedef struct {
    LinkNode *front, *rear;  // 队头和队尾指针
} LinkQueue;
```

**初始化**（带头节点）：
```c
void InitQueue(LinkQueue *Q) {
    Q->front = Q->rear = (LinkNode *)malloc(sizeof(LinkNode));
    Q->front->next = NULL;
}
```

**入队**：
```c
void EnQueue(LinkQueue *Q, ElemType x) {
    LinkNode *s = (LinkNode *)malloc(sizeof(LinkNode));
    s->data = x;
    s->next = NULL;
    Q->rear->next = s;
    Q->rear = s;
}
```

**出队**：
```c
bool DeQueue(LinkQueue *Q, ElemType *x) {
    if (Q->front == Q->rear) return false;
    LinkNode *p = Q->front->next;
    *x = p->data;
    Q->front->next = p->next;
    if (Q->rear == p) Q->rear = Q->front;  // 若队列只有一个元素
    free(p);
    return true;
}
```

> **注意**：出队时如果队列中只有一个元素，需要额外更新 rear 指针。

### 2.4 双端队列

双端队列（Deque）允许在**两端**都进行插入和删除操作。

- **输出受限的双端队列**：一端可以插入和删除，另一端只能插入
- **输入受限的双端队列**：一端可以插入和删除，另一端只能删除

> **考点**：判断一个输出序列是否可以由某种双端队列得到，是常考的选择题。

### 2.5 栈和队列的应用场景总结

| 应用场景 | 使用的数据结构 | 说明 |
|---------|--------------|------|
| 函数调用/递归 | 栈 | 保存返回地址和局部变量 |
| 括号匹配 | 栈 | 遇到左括号入栈，右括号匹配出栈 |
| 表达式求值 | 栈 | 操作数栈和运算符栈 |
| 进制转换 | 栈 | 短除法取余，余数入栈后逆序输出 |
| 迷宫求解 | 栈 | DFS 深度优先搜索 |
| 操作系统中的任务调度 | 队列 | FCFS 先来先服务 |
| 打印任务管理 | 队列 | 按提交顺序排队 |
| BFS 广度优先搜索 | 队列 | 层次遍历 |
| 操作系统中的缓冲区 | 队列 | 数据的缓冲和传递 |

## 三、栈和队列的改造与变体

本节讨论如何用其他存储结构（循环链表、双链表等）实现栈和队列，以及栈与队列之间的相互模拟，这些是 408 的常见综合题考点。

### 3.1 用循环单链表实现栈

栈可以用循环单链表实现，只设一个**栈顶指针** `top`，指向栈顶节点；栈底节点的 `next` 指回 `top`，形成环。

```c
typedef struct CLNode {
    ElemType data;
    struct CLNode *next;
} CLNode, *CLiStack;

void InitStack(CLiStack *top) { *top = NULL; }
bool StackEmpty(CLiStack top) { return top == NULL; }
```

循环单链表中在指定节点**之前**插入需要 O(n)，但**之后**插入是 O(1)。因此进栈采用"**后插 + 交换数据**"技巧，把 O(1) 的后插转化为栈顶插入：

```c
bool Push(CLiStack *top, ElemType x) {
    CLNode *s = (CLNode *)malloc(sizeof(CLNode));
    s->data = x;
    if (*top == NULL) {
        s->next = s;                // 唯一节点，自循环
        *top = s;
    } else {
        s->next = (*top)->next;     // ① 新节点插到栈顶之后
        (*top)->next = s;
        ElemType t = (*top)->data;  // ② 交换数据，使 x 成为新栈顶
        (*top)->data = s->data;
        s->data = t;
    }
    return true;
}

bool Pop(CLiStack *top, ElemType *x) {
    if (*top == NULL) return false;         // 栈空
    *x = (*top)->data;
    if ((*top)->next == *top) {             // 仅一个节点
        free(*top);
        *top = NULL;
    } else {
        CLNode *p = (*top)->next;           // 用后继数据覆盖栈顶，再删后继
        (*top)->data = p->data;
        (*top)->next = p->next;
        free(p);
    }
    return true;
}
```

> **技巧**：循环单链表中"在某节点之前插入"需 O(n)，而"之后插入"是 O(1)。利用"后插 + 交换数据"可把栈顶插入转化为 O(1) 操作；出栈同理用"后继覆盖 + 删后继"实现 O(1)。

### 3.2 用循环单链表实现队列（只设尾指针）

这是 408 的**高频考点**。用循环单链表实现队列时，只需设一个**尾指针** `rear`，队头节点就是 `rear->next`，入队和出队都能做到 O(1)。

```c
typedef struct CLNode {
    ElemType data;
    struct CLNode *next;
} CLNode, *CLQueue;    // CLQueue 即尾指针

void InitQueue(CLQueue *rear) { *rear = NULL; }
bool QueueEmpty(CLQueue rear) { return rear == NULL; }
```

**入队**（在队尾后插入，O(1)）：

```c
void EnQueue(CLQueue *rear, ElemType x) {
    CLNode *s = (CLNode *)malloc(sizeof(CLNode));
    s->data = x;
    if (*rear == NULL) {
        s->next = s;                  // 唯一节点，自循环
    } else {
        s->next = (*rear)->next;      // 新节点指向原队头
        (*rear)->next = s;            // 原队尾指向新节点
    }
    *rear = s;                        // 更新尾指针
}
```

**出队**（删除队头 `rear->next`，O(1)）：

```c
bool DeQueue(CLQueue *rear, ElemType *x) {
    if (*rear == NULL) return false;        // 队空
    CLNode *p = (*rear)->next;              // p 指向队头
    *x = p->data;
    if (p == *rear) {                       // 仅一个节点
        free(p);
        *rear = NULL;
    } else {
        (*rear)->next = p->next;            // 队尾跳过原队头
        free(p);
    }
    return true;
}
```

> **为什么只设尾指针就够？** 队列需在队尾插入、队头删除。若只设头指针，入队要遍历到表尾 O(n)；而循环链表中 `rear->next` 恰好是队头，因此只设尾指针即可同时 O(1) 访问队头和队尾。

**循环链表队列与顺序循环队列对比**：

| 对比项 | 顺序循环队列 | 循环链表队列（单尾指针） |
|--------|------------|----------------------|
| 存储结构 | 数组 + 取模 | 循环单链表 |
| 指针数量 | front、rear 两个 | 仅 rear 一个 |
| 容量限制 | 固定 MaxSize（需判满） | 无上限（动态分配） |
| 判空条件 | `front == rear` | `rear == NULL` |
| 判满 | 需特殊处理（牺牲单元等） | 无需判满（除非内存耗尽） |

### 3.3 两个栈模拟一个队列

用两个栈 `S1`（入队栈）、`S2`（出队栈）模拟一个队列：
- **入队**：直接压入 `S1`
- **出队**：若 `S2` 非空则弹出 `S2` 栈顶；否则将 `S1` 全部倒入 `S2`（顺序反转一次），再弹出 `S2` 栈顶

```c
typedef struct {
    SqStack S1, S2;
} MyQueue;

void EnQueue(MyQueue *Q, ElemType x) {
    Push(&Q->S1, x);
}

bool DeQueue(MyQueue *Q, ElemType *x) {
    if (!StackEmpty(Q->S2))               // S2 非空，直接出栈
        return Pop(&Q->S2, x);
    while (!StackEmpty(Q->S1)) {           // S2 空，把 S1 倒入 S2
        ElemType t;
        Pop(&Q->S1, &t);
        Push(&Q->S2, t);
    }
    if (StackEmpty(Q->S2)) return false;   // 两栈皆空，队空
    return Pop(&Q->S2, x);
}
```

> **复杂度**：入队 O(1)；出队最坏 O(n)，但每个元素最多被搬运两次（S1→S2），**均摊 O(1)**。注意只有 `S2` 为空时才能把 `S1` 倒入 `S2`，否则会破坏顺序。

### 3.4 两个队列模拟一个栈

用两个队列 `Q1`、`Q2` 模拟一个栈，采用"入栈 O(1)、出栈 O(n)"策略：始终只让一个队列存元素。

- **入栈**：把元素加入非空队列（都空则加入 `Q1`）
- **出栈**：将非空队列中除最后一个元素外全部搬到另一队列，剩下的那个即栈顶

```c
typedef struct {
    SqQueue Q1, Q2;
} MyStack;

void Push(MyStack *S, ElemType x) {
    if (!QueueEmpty(S->Q1)) EnQueue(&S->Q1, x);
    else EnQueue(&S->Q2, x);           // 都空时入 Q2
}

bool Pop(MyStack *S, ElemType *x) {
    if (QueueEmpty(S->Q1) && QueueEmpty(S->Q2)) return false;
    SqQueue *src, *dst;
    if (!QueueEmpty(S->Q1)) { src = &S->Q1; dst = &S->Q2; }
    else                    { src = &S->Q2; dst = &S->Q1; }
    while (QueueLength(*src) > 1) {     // 保留最后一个（长度按 2.2 节公式计算）
        ElemType t;
        DeQueue(src, &t);
        EnQueue(dst, &t);
    }
    return DeQueue(src, x);             // 最后一个即栈顶
}
```

> **对比**：也可采用"入栈 O(n)、出栈 O(1)"策略——入栈时先把新元素入空队列，再把另一队列全部搬过来，使新元素始终在队头。两种策略总有一个操作为 O(n)，因为队列无法像栈那样整体反转。

### 3.5 双端队列的链式实现

2.4 节介绍了双端队列的概念，这里给出基于**双链表**的实现，两端插入删除均为 O(1)：

```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;
} DNode;

typedef struct {
    DNode *front, *rear;   // 两端指针（带头节点时 front 指向头节点）
} Deque;
```

- **前端插入**：在 `front` 之后插入新节点
- **后端插入**：在 `rear` 之后（或之前）插入新节点
- **前端删除**：删除 `front` 的后继
- **后端删除**：删除 `rear`（或其前驱）

> **考点**：判断某输出序列能否由输入受限/输出受限双端队列得到，方法是枚举合法的进出队方式，常结合选择题考查。

### 3.6 最小栈（辅助栈）

设计一个支持 O(1) 获取最小值的栈：用一个**辅助栈**同步记录每个状态的最小值。

```c
typedef struct {
    SqStack data;   // 数据栈
    SqStack min;    // 辅助栈，栈顶始终为当前最小值
} MinStack;

void Push(MinStack *S, ElemType x) {
    Push(&S->data, x);
    if (StackEmpty(S->min) || x <= GetTop(S->min))
        Push(&S->min, x);               // 出现新最小值，入辅助栈
    else
        Push(&S->min, GetTop(S->min));  // 否则重复压入当前最小值
}

void Pop(MinStack *S, ElemType *x) {
    Pop(&S->data, x);
    ElemType m;
    Pop(&S->min, &m);                   // 同步弹出
}

ElemType GetMin(MinStack S) {
    return GetTop(S.min);               // O(1)
}
```

> **要点**：辅助栈与数据栈**同步进栈出栈**，保证任意时刻辅助栈栈顶都是当前数据栈的最小值。也可只在出现"更小或相等"的值时才压辅助栈，出栈时数据值等于辅助栈顶才弹辅助栈（节省空间）。

## 四、考点总结

1. **栈的 LIFO 特性**是核心，理解栈顶指针的含义
2. **循环队列的队空队满判断**是高频考点，重点掌握牺牲一个存储单元的方法
3. **中缀转后缀**是必考内容，需要熟练掌握转换规则
4. **递归与栈的关系**：理解函数调用栈的工作原理
5. **共享栈**的栈满条件：`top0 + 1 == top1`
6. **双端队列**的输出序列判断是易错点
7. **链式队列出队**时注意更新 rear 指针的特殊情况
8. **循环链表实现队列只设尾指针**：`rear->next` 即队头，入队出队均 O(1)，是综合题高频考点
9. **循环链表实现栈**：用"后插 + 交换数据""后继覆盖 + 删后继"实现 O(1) 进出栈
10. **两个栈模拟队列**：只有出队栈为空时才把入队栈倒入，均摊 O(1)
11. **两个队列模拟栈**：入栈 O(1) 出栈 O(n)（或反之），队列无法整体反转故必有一端 O(n)
