# 第五章——图

## 一、图的基本概念

### 1.1 图的定义

图 G 由顶点的有穷非空集合 V 和边的集合 E 组成，记为 G = (V, E)。

### 1.2 基本术语

#### 有向图与无向图

- **有向图**：每条边都有方向，用 `<v, w>` 表示从 v 指向 w 的弧
- **无向图**：每条边没有方向，用 `(v, w)` 或 `(w, v)` 表示

#### 完全图

- **无向完全图**：无向图中任意两个顶点之间都存在边，边数为 $\frac{n(n-1)}{2}$
- **有向完全图**：有向图中任意两个顶点之间都存在方向相反的两条弧，边数为 $n(n-1)$

#### 连通性

- **连通**（无向图）：顶点 v 到顶点 w 有路径存在
- **连通图**：无向图中任意两个顶点都是连通的
- **连通分量**：无向图中的极大连通子图
- **强连通**（有向图）：顶点 v 到顶点 w 和顶点 w 到顶点 v 都有路径
- **强连通图**：有向图中任意两个顶点都是强连通的
- **强连通分量**：有向图中的极大强连通子图

#### 度数

- **无向图**：顶点的度 = 与该顶点相连的边数。所有顶点的度数之和 = 2|E|
- **有向图**：
  - **入度（InDegree）**：以该顶点为终点的边数
  - **出度（OutDegree）**：以该顶点为起点的边数
  - 顶点的度 = 入度 + 出度。所有顶点的入度之和 = 所有顶点的出度之和 = |E|

#### 其他概念

| 术语 | 定义 |
|------|------|
| **简单图** | 不存在重复边和自环的图 |
| **子图** | 顶点集和边集都是原图子集的图 |
| **生成树** | 包含图中全部顶点的极小连通子图（n 个顶点，n-1 条边） |
| **生成森林** | 非连通图中各连通分量的生成树构成生成森林 |
| **路径长度** | 路径上边的数目 |
| **回路（环）** | 第一个顶点和最后一个顶点相同的路径 |
| **简单路径** | 路径中不重复出现顶点 |
| **简单回路** | 除首尾顶点外，不重复出现顶点的回路 |

## 二、图的存储结构

### 2.1 邻接矩阵

用一个二维数组 `arc[n][n]` 表示图中顶点之间的关系。

```c
#define MaxVertexNum 100
typedef struct {
    char Vex[MaxVertexNum];           // 顶点表
    int Edge[MaxVertexNum][MaxVertexNum]; // 邻接矩阵（边表）
    int vexNum, edgeNum;             // 顶点数和边数
} MGraph;
```

**无向图**：邻接矩阵是**对称矩阵**，`Edge[i][j] = Edge[j][i]`

**有向图**：邻接矩阵**不一定对称**

| 特点 | 说明 |
|------|------|
| 空间复杂度 | O(n^2)，适合存储稠密图 |
| 查找邻接点 | O(n)，需要扫描一行或一列 |
| 判断两点间是否有边 | O(1) |
| 计算顶点的度 | 无向图：扫描一行 O(n)；有向图：入度扫描一列，出度扫描一行 |

### 2.2 邻接表

对每个顶点建立一个单链表，存储该顶点的所有邻接点。

```c
typedef struct ArcNode {     // 边表节点
    int adjvex;               // 该边所指向的顶点的位置
    struct ArcNode *next;     // 指向下一条边的指针
    // InfoType info;         // 可选：边的权值等信息
} ArcNode;

typedef struct VNode {       // 顶点表节点
    char data;                // 顶点信息
    ArcNode *firstarc;        // 指向第一条边的指针
} VNode;

typedef struct {
    VNode adjlist[MaxVertexNum]; // 邻接表
    int vexNum, edgeNum;
} ALGraph;
```

| 特点 | 说明 |
|------|------|
| 空间复杂度 | O(n + e)，适合存储稀疏图 |
| 查找邻接点 | 只需遍历链表 |
| 计算顶点的度 | 无向图：链表长度；有向图：出度=链表长度，入度需遍历所有链表 |

> **注意**：有向图的邻接表中，计算入度需要遍历所有顶点的链表，时间复杂度 O(n + e)。可以建立**逆邻接表**来方便计算入度。

### 2.3 十字链表（Orthogonal List）

**十字链表是有向图的一种链式存储结构**，将邻接表和逆邻接表结合起来，方便同时访问顶点的出边和入边。

#### 节点结构

**弧节点（边节点）**：

| tailVex | headVex | hlink | tlink | info |
|---------|---------|-------|-------|------|
| 弧尾顶点位置 | 弧头顶点位置 | 指向同弧头的下条弧 | 指向同弧尾的下条弧 | 弧信息 |

**顶点节点**：

| data | firstin | firstout |
|------|---------|----------|
| 顶点数据 | 指向以该顶点为弧头的第一条弧 | 指向以该顶点为弧尾的第一条弧 |

#### 存储结构定义

```c
typedef struct ArcBox {       // 弧节点
    int tailVex, headVex;     // 弧尾、弧头顶点位置
    struct ArcBox *hlink;     // 指向同弧头的下一条弧（入边链表）
    struct ArcBox *tlink;     // 指向同弧尾的下一条弧（出边链表）
    // InfoType info;         // 弧信息
} ArcBox;

typedef struct VexNode {      // 顶点节点
    char data;
    ArcBox *firstin;          // 指向第一条入弧
    ArcBox *firstout;         // 指向第一条出弧
} VexNode;

typedef struct {
    VexNode xlist[MaxVertexNum];
    int vexNum, arcNum;
} OLGraph;
```

#### 特点

| 特点 | 说明 |
|------|------|
| 空间复杂度 | O(n + e)，每条弧只有一个弧节点 |
| 查找出边 | 沿 `firstout` 链表，等价于邻接表 |
| 查找入边 | 沿 `firstin` 链表，等价于逆邻接表 |
| 适用场景 | **有向图**，需频繁查询入度和出度 |

> **要点**：十字链表中每条弧同时挂在两个链表上（弧头链表和弧尾链表），因此既容易求出度也容易求入度，是有向图最实用的链式存储。

### 2.4 邻接多重表（Adjacency Multilist）

**邻接多重表是无向图的一种链式存储结构**，每条边只用一个节点表示，解决了邻接表中无向图每条边存储两次的冗余问题。

#### 节点结构

**边节点**：

| mark | ivex | ilink | jvex | jlink | info |
|------|------|-------|------|-------|------|
| 访问标记 | 顶点 i 位置 | 指向下一条依附于 i 的边 | 顶点 j 位置 | 指向下一条依附于 j 的边 | 边信息 |

**顶点节点**：

| data | firstedge |
|------|-----------|
| 顶点数据 | 指向第一条依附于该顶点的边 |

#### 存储结构定义

```c
typedef struct EBox {         // 边节点
    bool mark;                // 访问标记
    int ivex, jvex;           // 该边依附的两个顶点位置
    struct EBox *ilink;       // 指向下一条依附于 ivex 的边
    struct EBox *jlink;       // 指向下一条依附于 jvex 的边
    // InfoType info;         // 边信息
} EBox;

typedef struct VexBox {       // 顶点节点
    char data;
    EBox *firstedge;          // 指向第一条依附于该顶点的边
} VexBox;

typedef struct {
    VexBox adjmulist[MaxVertexNum];
    int vexNum, edgeNum;
} AMLGraph;
```

#### 特点

| 特点 | 说明 |
|------|------|
| 空间复杂度 | O(n + e)，每条边只存一次，比邻接表节省空间 |
| 删除边 | 需修改两个指针（ilink 和 jlink），较邻接表复杂 |
| 适用场景 | **无向图**，尤其需要对边进行标记或删除操作 |

### 2.5 四种存储结构对比

| 存储结构 | 适用图类型 | 空间复杂度 | 查找边 | 求度 |
|---------|-----------|-----------|--------|------|
| 邻接矩阵 | 有向/无向 | O(n²) | O(1) | O(n) |
| 邻接表 | 有向/无向 | O(n+e) | O(度数) | 无向：O(度数)；有向出度易、入度难 |
| 十字链表 | 有向图 | O(n+e) | O(度数) | 入度、出度均易 |
| 邻接多重表 | 无向图 | O(n+e) | O(度数) | O(度数) |

## 三、图的遍历

### 3.1 深度优先搜索（DFS）

#### 算法思想

从某个顶点出发，访问该顶点，然后递归地访问其未被访问过的邻接点，直到所有可达顶点都被访问。

#### 算法描述（邻接表实现）

```c
bool visited[MaxVertexNum];  // 访问标记数组

void DFS(ALGraph G, int v) {
    visit(v);                 // 访问顶点 v
    visited[v] = true;
    for (ArcNode *p = G.adjlist[v].firstarc; p != NULL; p = p->next) {
        int w = p->adjvex;
        if (!visited[w])
            DFS(G, w);        // 递归访问
    }
}

void DFSTraverse(ALGraph G) {
    for (int i = 0; i < G.vexNum; i++)
        visited[i] = false;   // 初始化
    for (int i = 0; i < G.vexNum; i++)
        if (!visited[i])
            DFS(G, i);        // 对每个连通分量调用 DFS
}
```

#### DFS 非递归实现

```c
void DFS_NonRecur(ALGraph G, int v) {
    SqStack S;
    InitStack(&S);
    Push(&S, v);
    visited[v] = true;
    while (!StackEmpty(S)) {
        int u;
        Pop(&S, &u);
        visit(u);
        for (ArcNode *p = G.adjlist[u].firstarc; p != NULL; p = p->next) {
            int w = p->adjvex;
            if (!visited[w]) {
                Push(&S, w);
                visited[w] = true;
            }
        }
    }
}
```

#### 时间复杂度

- **邻接矩阵**：O(n^2)（每个顶点都要扫描一行）
- **邻接表**：O(n + e)（每个顶点和每条边各访问一次）

#### 空间复杂度

O(n)（递归栈或显式栈的空间）

### 3.2 广度优先搜索（BFS）

#### 算法思想

从某个顶点出发，先访问该顶点，然后访问其所有未被访问的邻接点，再依次访问这些邻接点的邻接点，逐层扩展。

#### 算法描述（邻接表实现）

```c
void BFS(ALGraph G, int v) {
    Queue Q;
    InitQueue(&Q);
    visit(v);
    visited[v] = true;
    EnQueue(&Q, v);
    while (!QueueEmpty(Q)) {
        int u;
        DeQueue(&Q, &u);
        for (ArcNode *p = G.adjlist[u].firstarc; p != NULL; p = p->next) {
            int w = p->adjvex;
            if (!visited[w]) {
                visit(w);
                visited[w] = true;
                EnQueue(&Q, w);
            }
        }
    }
}
```

#### 时间复杂度

- **邻接矩阵**：O(n^2)
- **邻接表**：O(n + e)

#### 空间复杂度

O(n)（队列的空间）

### 3.3 DFS 与 BFS 的对比

| 对比项 | DFS | BFS |
|--------|-----|-----|
| 数据结构 | 栈（递归栈） | 队列 |
| 遍历方式 | 深度优先，类似树的前序遍历 | 广度优先，类似树的层序遍历 |
| 最短路径 | 不保证 | 无权图中可以找到最短路径 |
| 适用场景 | 路径搜索、连通性判断、拓扑排序 | 最短路径、层次遍历 |

## 四、最小生成树

### 4.1 最小生成树的概念

给定一个带权无向连通图 G，包含 G 中所有顶点的树称为 G 的生成树。所有生成树中，**边的权值之和最小**的生成树称为**最小生成树（MST）**。

性质：
- 最小生成树的边数为 n - 1
- 最小生成树不一定唯一，但权值之和唯一
- 如果图中各边权值互不相同，则最小生成树唯一

### 4.2 Prim 算法（普里姆算法）

#### 算法思想

从某个顶点开始，每次选择与已加入生成树的顶点集相连的**权值最小**的边，将该边及其另一端顶点加入生成树，直到所有顶点都加入。

#### 执行过程示例

图 G 的边及权值：`(A,B,6), (A,C,1), (A,D,5), (B,C,5), (B,E,3), (C,D,5), (C,E,6), (C,F,4), (D,F,2), (E,F,6)`

| 步骤 | 已加入顶点集 | 候选边 | 选取边 | 权值 |
|------|------------|--------|--------|------|
| 1 | {A} | (A,B,6), (A,C,1), (A,D,5) | (A,C) | 1 |
| 2 | {A,C} | (A,B,6), (A,D,5), (C,B,5), (C,D,5), (C,E,6), (C,F,4) | (C,F) | 4 |
| 3 | {A,C,F} | (A,B,6), (A,D,5), (C,B,5), (C,D,5), (C,E,6), (F,D,2), (F,E,6) | (F,D) | 2 |
| 4 | {A,C,F,D} | (A,B,6), (C,B,5), (C,D,5), (C,E,6), (D,B,*) | (C,B) | 5 |
| 5 | {A,C,F,D,B} | (B,E,3), (C,E,6), (F,E,6) | (B,E) | 3 |

**最小生成树权值之和** = 1 + 4 + 2 + 5 + 3 = **15**

#### 时间复杂度

O(n^2)，不依赖于边数，适合**稠密图**。

### 4.3 Kruskal 算法（克鲁斯卡尔算法）

#### 算法思想

将所有边按权值从小到大排序，依次选取每条边，若该边连接的两个顶点不在同一个连通分量中（不形成回路），则加入最小生成树，直到选取了 n - 1 条边。

需要使用**并查集**来判断两个顶点是否在同一连通分量中。

#### 执行过程示例

同上图，按权值排序后的边：
`(A,C,1), (F,D,2), (B,E,3), (C,F,4), (C,B,5), (C,D,5), (A,D,5), (A,B,6), (C,E,6), (E,F,6)`

| 步骤 | 选取边 | 权值 | 是否加入 | 原因 |
|------|--------|------|---------|------|
| 1 | (A,C) | 1 | 加入 | A, C 不连通 |
| 2 | (F,D) | 2 | 加入 | F, D 不连通 |
| 3 | (B,E) | 3 | 加入 | B, E 不连通 |
| 4 | (C,F) | 4 | 加入 | C, F 不连通 |
| 5 | (C,B) | 5 | 加入 | C, B 不连通 |
| 6 | (C,D) | 5 | 不加入 | C, D 已连通（通过 C-F-D） |
| 7 | (A,D) | 5 | 不加入 | A, D 已连通（通过 A-C-F-D） |

已选 5 条边（n - 1 = 5），算法结束。

**最小生成树权值之和** = 1 + 2 + 3 + 4 + 5 = **15**

#### 时间复杂度

O(e log e) = O(e log n)，主要取决于边数，适合**稀疏图**。

## 五、最短路径

### 5.1 Dijkstra 算法

#### 适用条件

解决**单源最短路径**问题，不能处理**负权边**。

#### 算法思想

维护一个集合 S（已确定最短路径的顶点集）和数组 dist（各顶点到源点的当前最短路径估计值）。每次从 V - S 中选取 dist 最小的顶点 u 加入 S，然后以 u 为中转点更新其他顶点的 dist 值。

#### 计算示例

有向图带权，求从顶点 0 到各顶点的最短路径：

邻接矩阵（INF 表示不可达）：
```
     0    1    2    3    4
0 [  0   10   INF   30  100]
1 [ INF   0   50   INF  INF]
2 [ INF  INF   0   INF   10]
3 [ INF  INF  20   INF   60]
4 [ INF  INF  INF  INF   0 ]
```

| 步骤 | S 集合 | u | dist[0] | dist[1] | dist[2] | dist[3] | dist[4] |
|------|--------|---|---------|---------|---------|---------|---------|
| 初始 | {} | - | 0 | 10 | INF | 30 | 100 |
| 1 | {0} | 1 | 0 | **10** | 60 | 30 | 100 |
| 2 | {0,1} | 3 | 0 | 10 | 50 | **30** | 90 |
| 3 | {0,1,3} | 2 | 0 | 10 | **50** | 30 | 70 |
| 4 | {0,1,3,2} | 4 | 0 | 10 | 50 | 30 | **70** |
| 5 | {0,1,3,2,4} | - | 0 | 10 | 50 | 30 | 70 |

**最短路径结果**：
- 0→1: 10
- 0→3: 30
- 0→1→2: 50
- 0→3→2→4: 70

#### 时间复杂度

O(n^2)（使用邻接矩阵），适合稠密图。

### 5.2 Floyd 算法

#### 适用条件

解决**所有顶点对之间的最短路径**问题，可以处理负权边（但不能有负权回路）。

#### 算法思想

动态规划。设 $A^{(k)}[i][j]$ 表示仅经过顶点 0~k 的从 i 到 j 的最短路径长度。

递推公式：
$$A^{(k)}[i][j] = \min(A^{(k-1)}[i][j], A^{(k-1)}[i][k] + A^{(k-1)}[k][j])$$

#### 计算示例

图的邻接矩阵（4 个顶点）：
```
     0    1    2    3
0 [  0    1   INF   4 ]
1 [ INF   0   9    2 ]
2 [  3   INF   0   INF]
3 [  5   INF   6    0 ]
```

**初始** $A^{(-1)}$（即原始邻接矩阵）：
```
A[0][0]=0  A[0][1]=1  A[0][2]=INF  A[0][3]=4
A[1][0]=INF A[1][1]=0  A[1][2]=9   A[1][3]=2
A[2][0]=3  A[2][1]=INF A[2][2]=0   A[2][3]=INF
A[3][0]=5  A[3][1]=INF A[3][2]=6   A[3][3]=0
```

**k=0**（经过顶点 0）：
- A[2][1] = min(INF, 3+1) = 4
- A[3][1] = min(INF, 5+1) = 6

**k=1**（经过顶点 0, 1）：
- A[0][2] = min(INF, 1+9) = 10
- A[0][3] = min(4, 1+2) = 3
- A[2][3] = min(INF, 4+2) = 6

**k=2**（经过顶点 0, 1, 2）：
- A[1][0] = min(INF, 9+3) = 12
- A[1][3] = min(2, 9+6) = 2
- A[3][0] = min(5, 6+3) = 5
- A[3][1] = min(6, 6+4) = 6

**k=3**（经过顶点 0, 1, 2, 3）：
- A[0][2] = min(10, 3+6) = 9
- A[1][0] = min(12, 2+5) = 7
- A[1][2] = min(9, 2+6) = 8

**最终结果**：
```
     0    1    2    3
0 [  0    1    9    3 ]
1 [  7    0    8    2 ]
2 [  3    4    0    6 ]
3 [  5    6    6    0 ]
```

#### 时间复杂度

O(n^3)，空间复杂度 O(n^2)。

## 六、拓扑排序

### 6.1 AOV 网

**顶点表示活动（Activity On Vertex）**的有向无环图（DAG）。用顶点表示活动，用边表示活动之间的先后关系。

### 6.2 拓扑排序算法

#### 算法思想

1. 从有向图中选择一个**没有前驱**（入度为 0）的顶点输出
2. 从图中删除该顶点以及所有以它为起点的边
3. 重复步骤 1-2，直到所有顶点都输出（拓扑排序成功）或图中还有顶点但无入度为 0 的顶点（图中存在回路）

#### 算法实现

```c
bool TopologicalSort(ALGraph G, int topo[]) {
    int indegree[MaxVertexNum];  // 入度数组
    // 计算各顶点入度
    for (int i = 0; i < G.vexNum; i++)
        for (ArcNode *p = G.adjlist[i].firstarc; p != NULL; p = p->next)
            indegree[p->adjvex]++;

    // 将入度为 0 的顶点入队
    Queue Q;
    InitQueue(&Q);
    for (int i = 0; i < G.vexNum; i++)
        if (indegree[i] == 0) EnQueue(&Q, i);

    int count = 0;  // 记录已输出的顶点数
    while (!QueueEmpty(Q)) {
        int u;
        DeQueue(&Q, &u);
        topo[count++] = u;  // 输出顶点
        for (ArcNode *p = G.adjlist[u].firstarc; p != NULL; p = p->next) {
            int w = p->adjvex;
            if (--indegree[w] == 0)  // 删除边后入度减 1
                EnQueue(&Q, w);
        }
    }
    return count == G.vexNum;  // 若所有顶点都输出，则无回路
}
```

#### 时间复杂度

O(n + e)

> **注意**：拓扑排序的结果不一定是唯一的。若图中存在回路，则无法完成拓扑排序。

## 七、关键路径

### 7.1 AOE 网

**边表示活动（Activity On Edge）**的有向无环图。用顶点表示**事件**，用边表示**活动**，边的权值表示活动持续的时间。

### 7.2 关键路径的概念

从源点到汇点的**最长路径**称为关键路径。关键路径上的活动称为**关键活动**，它们的延迟将导致整个工程延期。

### 7.3 关键参数

- **事件 v_i 的最早发生时间 ve(i)**：从源点到 v_i 的最长路径长度
  - $ve(源点) = 0$
  - $ve(j) = \max\{ve(i) + w(i,j)\}$（对所有指向 j 的边 `<i,j>`）

- **事件 v_i 的最迟发生时间 vl(i)**：在不推迟整个工期的前提下，v_i 最迟必须发生的时间
  - $vl(汇点) = ve(汇点)$
  - $vl(i) = \min\{vl(j) - w(i,j)\}$（对所有从 i 出发的边 `<i,j>`）

- **活动 a_k 的最早开始时间 e(k)**：= 该活动起点事件的最早发生时间
  - $e(k) = ve(i)$（活动 $a_k = <i,j>$）

- **活动 a_k 的最迟开始时间 l(k)**：= 该活动终点事件的最迟发生时间 - 活动持续时间
  - $l(k) = vl(j) - w(i,j)$

- **关键活动**：$l(k) = e(k)$ 的活动，即时间余量为 0 的活动

### 7.4 关键路径计算示例

AOE 网：

```
V0 --a1(6)--> V1 --a2(4)--> V3
|              |              |
a3(3)         a4(2)         a6(3)
|              |              |
V2 --a5(5)--> V4 --a7(1)--> V5
```

顶点：V0(源点), V1, V2, V3, V4, V5(汇点)
活动：a1=6, a2=4, a3=3, a4=2, a5=5, a6=3, a7=1

**第一步：求 ve（最早发生时间）**

按拓扑排序顺序：
- ve(0) = 0
- ve(1) = ve(0) + a1 = 0 + 6 = 6
- ve(2) = ve(0) + a3 = 0 + 3 = 3
- ve(3) = max(ve(1) + a2, ve(0) + ?) = max(6 + 4) = 10
  - 注意：V3 的前驱是 V1（通过 a2），ve(3) = ve(1) + a2 = 6 + 4 = 10
- ve(4) = max(ve(1) + a4, ve(2) + a5) = max(6 + 2, 3 + 5) = max(8, 8) = 8
- ve(5) = max(ve(3) + a6, ve(4) + a7) = max(10 + 3, 8 + 1) = max(13, 9) = 13

**第二步：求 vl（最迟发生时间）**

按逆拓扑排序顺序：
- vl(5) = ve(5) = 13
- vl(4) = vl(5) - a7 = 13 - 1 = 12
- vl(3) = vl(5) - a6 = 13 - 3 = 10
- vl(1) = min(vl(3) - a2, vl(4) - a4) = min(10 - 4, 12 - 2) = min(6, 10) = 6
- vl(2) = vl(4) - a5 = 12 - 5 = 7
- vl(0) = min(vl(1) - a1, vl(2) - a3) = min(6 - 6, 7 - 3) = min(0, 4) = 0

**第三步：求各活动的 e 和 l**

| 活动 | e(k) = ve(i) | l(k) = vl(j) - w | l - e | 是否关键活动 |
|------|-------------|-------------------|-------|------------|
| a1: V0→V1 | ve(0) = 0 | vl(1) - 6 = 0 | 0 | 是 |
| a2: V1→V3 | ve(1) = 6 | vl(3) - 4 = 6 | 0 | 是 |
| a3: V0→V2 | ve(0) = 0 | vl(2) - 3 = 4 | 4 | 否 |
| a4: V1→V4 | ve(1) = 6 | vl(4) - 2 = 10 | 4 | 否 |
| a5: V2→V4 | ve(2) = 3 | vl(4) - 5 = 7 | 4 | 否 |
| a6: V3→V5 | ve(3) = 10 | vl(5) - 3 = 10 | 0 | 是 |
| a7: V4→V5 | ve(4) = 8 | vl(5) - 1 = 12 | 4 | 否 |

**关键路径**：V0 → V1 → V3 → V5（对应关键活动 a1, a2, a6）

**关键路径长度**：6 + 4 + 3 = **13**

## 八、算法复杂度汇总

### 8.1 图的遍历算法复杂度

| 算法 | 邻接矩阵时间 | 邻接表时间 | 空间复杂度 |
|------|------------|-----------|-----------|
| DFS | O(n²) | O(n + e) | O(n)（递归栈/显式栈） |
| BFS | O(n²) | O(n + e) | O(n)（队列） |

### 8.2 最小生成树算法复杂度

| 算法 | 时间复杂度 | 适用图类型 | 说明 |
|------|-----------|-----------|------|
| Prim | O(n²) | 稠密图 | 与边数无关，适合边稠密的图 |
| Kruskal | O(e log e) | 稀疏图 | 主要耗费在排序，适合边稀疏的图 |

> Prim 优化：使用最小堆可将时间复杂度降至 O(e log n)；Kruskal 的 O(e log e) 等价于 O(e log n)（因 e ≤ n²）。

### 8.3 最短路径算法复杂度

| 算法 | 时间复杂度 | 空间复杂度 | 适用条件 |
|------|-----------|-----------|---------|
| Dijkstra（邻接矩阵） | O(n²) | O(n) | 单源最短路径，无负权边 |
| Dijkstra（邻接表+最小堆） | O(e log n) | O(n) | 单源最短路径，无负权边 |
| Floyd | O(n³) | O(n²) | 所有顶点对最短路径，可有负权边（无负权回路） |
| BFS（无权图） | O(n + e) | O(n) | 单源最短路径，无权图 |

### 8.4 拓扑排序与关键路径复杂度

| 算法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 拓扑排序 | O(n + e) | O(n) | 入度数组 + 队列 |
| 关键路径 | O(n + e) | O(n) | 基于拓扑排序，需两次遍历 |

### 8.5 图算法复杂度速查总表

| 算法 | 时间复杂度 | 空间复杂度 | 备注 |
|------|-----------|-----------|------|
| DFS | O(n+e) / O(n²) | O(n) | 邻接表 / 邻接矩阵 |
| BFS | O(n+e) / O(n²) | O(n) | 邻接表 / 邻接矩阵 |
| Prim | O(n²) | O(n) | 稠密图 |
| Kruskal | O(e log e) | O(n+e) | 稀疏图，需并查集 |
| Dijkstra | O(n²) | O(n) | 单源，无负权 |
| Floyd | O(n³) | O(n²) | 多源，可负权 |
| 拓扑排序 | O(n+e) | O(n) | DAG |
| 关键路径 | O(n+e) | O(n) | AOE 网 |

## 九、考点总结

1. **图的存储**：邻接矩阵 vs 邻接表 vs 十字链表 vs 邻接多重表，空间复杂度和适用场景
2. **十字链表**：有向图专用，同时方便求入度和出度，每条弧只存一次
3. **邻接多重表**：无向图专用，每条边只存一次，适合边的标记和删除
4. **DFS 和 BFS**：时间复杂度、空间复杂度、遍历序列
5. **最小生成树**：Prim（O(n²)，适合稠密图）vs Kruskal（O(e log e)，适合稀疏图），构造过程
6. **最短路径**：Dijkstra（O(n²)，单源、无负权边）vs Floyd（O(n³)，多源、可有负权边）
7. **拓扑排序**：AOV 网、入度为 0 的顶点优先，O(n+e)
8. **关键路径**：AOE 网、ve/vl/e/l 的计算，关键活动的判定，O(n+e)
9. **算法复杂度对比**：参见第八节速查总表，重点掌握各算法的时间/空间复杂度
10. **连通分量和强连通分量**的概念和求解方法
