# 第三章——串

## 一、串的定义与基本操作

### 1.1 串的定义

串（String）是由零个或多个字符组成的有限序列。串中字符的数目 n 称为串的**长度**。

- **空串**：长度为 0 的串，不包含任何字符
- **空白串**：由一个或多个空格组成的串，长度 > 0
- **子串**：串中任意个连续的字符组成的子序列
- **主串**：包含子串的串
- **字符在串中的位置**：字符在串中的序号（从 1 开始）

> **注意**：空串是任何串的子串，任何串都是自身的子串。

### 1.2 串的基本操作

| 操作 | 功能描述 |
|------|---------|
| `StrAssign(&T, chars)` | 赋值操作，将串常量 chars 赋给 T |
| `StrCopy(&T, S)` | 复制操作，将串 S 复制到 T |
| `StrEmpty(S)` | 判断串 S 是否为空串 |
| `StrCompare(S, T)` | 比较操作，若 S > T 返回 >0，S = T 返回 0，S < T 返回 <0 |
| `StrLength(S)` | 返回串 S 的长度 |
| `SubString(&Sub, S, pos, len)` | 求子串，用 Sub 返回 S 的第 pos 个字符起长度为 len 的子串 |
| `Concat(&T, S1, S2)` | 连接操作，用 T 返回 S1 和 S2 连接而成的新串 |
| `Index(S, T)` | 定位操作，返回子串 T 在主串 S 中第一次出现的位置 |
| `Replace(&S, T, V)` | 替换操作，用 V 替换 S 中所有出现的 T |
| `StrInsert(&S, pos, T)` | 在串 S 的第 pos 个字符之前插入串 T |
| `StrDelete(&S, pos, len)` | 从串 S 中删除第 pos 个字符起长度为 len 的子串 |

### 1.3 串的存储结构

#### 定长顺序存储

```c
#define MaxLen 255
typedef struct {
    char ch[MaxLen];  // 每个分量存储一个字符
    int length;
} SString;
```

#### 堆分配存储

```c
typedef struct {
    char *ch;     // 按串长分配存储区，ch 指向串的基地址
    int length;
} HString;
```

#### 块链存储

每个节点可以存储多个字符，当节点大小 > 1 时，串的存储不一定是字符对齐的。

## 二、串的模式匹配

模式匹配：在主串 S 中查找与模式串 T 相同的子串，返回子串在主串中的位置。

### 2.1 朴素模式匹配算法（Brute-Force）

#### 算法思想

从主串的第一个字符开始，与模式串逐个比较。若匹配失败，则从主串的下一个字符重新开始与模式串比较。

```c
int Index_BF(SString S, SString T) {
    int i = 1, j = 1;
    while (i <= S.length && j <= T.length) {
        if (S.ch[i] == T.ch[j]) {
            i++; j++;  // 继续比较后续字符
        } else {
            i = i - j + 2;  // 主串指针回退到本次匹配起点的下一个位置
            j = 1;          // 模式串指针回到开头
        }
    }
    if (j > T.length) return i - T.length;  // 匹配成功
    return 0;  // 匹配失败
}
```

#### 时间复杂度分析

- **最好情况**：主串第一个字符开始就匹配成功，比较次数为 m（模式串长度），**O(m)**
- **最坏情况**：每次匹配到模式串最后一个字符才失败
  - 主串：`00000000000000000001`（n-1 个 0 和 1 个 1）
  - 模式串：`0001`（m-1 个 0 和 1 个 1）
  - 每次比较 m 次，共比较 n - m + 1 次
  - 总比较次数：$(n - m + 1) \times m$
  - **最坏时间复杂度：O(mn)**

- **平均时间复杂度：O(mn)**

#### BF 算法执行示例

主串 S = `ababcabcacbab`，模式串 T = `abcac`

| 匹配轮次 | i | j | 比较 | 结果 |
|---------|---|---|------|------|
| 第 1 轮 | 1 | 1 | a=a, b=b, a!=c | 失败，i=3, j=1 |
| 第 2 轮 | 3 | 1 | a=a, b!=a | 失败，i=4, j=1 |
| 第 3 轮 | 4 | 1 | b!=a | 失败，i=5, j=1 |
| 第 4 轮 | 5 | 1 | a=a, b=b, c=c, a=a, c=c | **成功！** 返回 i - m = 5 |

### 2.2 KMP 算法

#### 算法思想

KMP 算法的核心是：当匹配失败时，**主串指针 i 不回退**，只移动模式串指针 j，利用已经匹配过的信息来避免不必要的比较。

关键问题：当匹配失败时，模式串指针 j 应该回退到哪里？

引入 **next 数组**：`next[j]` 表示当模式串第 j 个字符匹配失败时，模式串应该回退到的位置。

#### next 数组的定义

`next[j]` = 模式串 T 中，以第 j 个字符为结尾的子串的**最长相等前后缀长度 + 1**

即：`next[j]` = `max{k | 1 <= k < j, 且 T[1...k-1] = T[j-k+1...j-1]}` + 1

**特殊情况**：
- `next[1] = 0`（第一个字符匹配失败，i 和 j 都要后移）
- `next[2] = 1`（第二个字符匹配失败，回退到第一个字符）

#### next 数组的求解

```c
void getNext(SString T, int next[]) {
    int i = 1, j = 0;
    next[1] = 0;
    while (i < T.length) {
        if (j == 0 || T.ch[i] == T.ch[j]) {
            i++; j++;
            next[i] = j;
        } else {
            j = next[j];
        }
    }
}
```

#### next 数组求解完整示例

模式串 T = `ababaaab`

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| T[j] | a | b | a | b | a | a | a | b |
| next[j] | 0 | 1 | 1 | 2 | 3 | 4 | 2 | 2 |

**求解过程详解**：

- `j = 1`：`next[1] = 0`（固定值）
- `j = 2`：子串 `b`，无前缀后缀相等，`next[2] = 1`
- `j = 3`：子串 `ab`，前缀 `a`，后缀 `b`，不相等，`next[3] = 1`
- `j = 4`：子串 `aba`，前缀 `a` = 后缀 `a`，长度 1，`next[4] = 1 + 1 = 2`
- `j = 5`：子串 `abab`，前缀 `ab` = 后缀 `ab`，长度 2，`next[5] = 2 + 1 = 3`
- `j = 6`：子串 `ababa`，前缀 `aba` = 后缀 `aba`，长度 3，`next[6] = 3 + 1 = 4`
- `j = 7`：子串 `ababaa`，前缀 `a` = 后缀 `a`，长度 1（注意不是 `aba` != `baa`），`next[7] = 1 + 1 = 2`
- `j = 8`：子串 `ababaaa`，前缀 `ab` = 后缀 `ab`，长度 2，`next[8] = 2 + 1 = 3`

> **修正**：让我重新计算 j=7 和 j=8。

重新计算模式串 T = `ababaaab`：

- `j = 7`：子串 `ababaa`，前缀集合 {a, ab, aba, abab, ababa}，后缀集合 {a, aa, baa, abaa, babaa}，最长相等前后缀为 `a`（长度 1），`next[7] = 2`
- `j = 8`：子串 `ababaaa`，前缀集合 {a, ab, aba, abab, ababa, ababaa}，后缀集合 {a, aa, aaa, baaa, abaaa, babaaa}，最长相等前后缀为 `a`（长度 1），`next[8] = 2`

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| T[j] | a | b | a | b | a | a | a | b |
| next[j] | 0 | 1 | 1 | 2 | 3 | 4 | 2 | 2 |

#### KMP 匹配算法

```c
int Index_KMP(SString S, SString T, int next[]) {
    int i = 1, j = 1;
    while (i <= S.length && j <= T.length) {
        if (j == 0 || S.ch[i] == T.ch[j]) {
            i++; j++;
        } else {
            j = next[j];  // 模式串回退
        }
    }
    if (j > T.length) return i - T.length;
    return 0;
}
```

#### KMP 匹配过程完整示例

主串 S = `ababcabcacbab`，模式串 T = `abcac`

先求 next 数组：

| j | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| T[j] | a | b | c | a | c |
| next[j] | 0 | 1 | 1 | 1 | 2 |

匹配过程：

| 步骤 | i | j | S[i] | T[j] | 比较 | 操作 |
|------|---|---|------|------|------|------|
| 1 | 1 | 1 | a | a | 相等 | i=2, j=2 |
| 2 | 2 | 2 | b | b | 相等 | i=3, j=3 |
| 3 | 3 | 3 | a | c | 不等 | j = next[3] = 1 |
| 4 | 3 | 1 | a | a | 相等 | i=4, j=2 |
| 5 | 4 | 2 | b | b | 相等 | i=5, j=3 |
| 6 | 5 | 3 | c | c | 相等 | i=6, j=4 |
| 7 | 6 | 4 | a | a | 相等 | i=7, j=5 |
| 8 | 7 | 5 | b | c | 不等 | j = next[5] = 2 |
| 9 | 7 | 2 | b | b | 相等 | i=8, j=3 |
| 10 | 8 | 3 | c | c | 相等 | i=9, j=4 |
| 11 | 9 | 4 | a | a | 相等 | i=10, j=5 |
| 12 | 10 | 5 | c | c | 相等 | i=11, j=6 |

j > T.length，匹配成功！返回 `i - T.length = 11 - 5 = 6`

> **对比 BF 算法**：BF 算法在第 1 轮匹配失败后 i 回退到 3，而 KMP 算法中 i 始终不回退。

#### KMP 算法的时间复杂度

- **求 next 数组**：O(m)
- **匹配过程**：O(n)
- **总时间复杂度：O(m + n)**

#### nextval 数组（优化的 next 数组）

当 `T[j] == T[next[j]]` 时，匹配失败后回退到 `next[j]` 位置仍然会失败，可以进一步优化。

```c
void getNextval(SString T, int nextval[]) {
    int i = 1, j = 0;
    nextval[1] = 0;
    while (i < T.length) {
        if (j == 0 || T.ch[i] == T.ch[j]) {
            i++; j++;
            if (T.ch[i] != T.ch[j])
                nextval[i] = j;
            else
                nextval[i] = nextval[j];
        } else {
            j = nextval[j];
        }
    }
}
```

**nextval 求解示例**：模式串 T = `ababaaab`

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| T[j] | a | b | a | b | a | a | a | b |
| next[j] | 0 | 1 | 1 | 2 | 3 | 4 | 2 | 2 |
| nextval[j] | 0 | 1 | 0 | 1 | 0 | 4 | 2 | 1 |

**求解过程**：
- `nextval[1] = 0`（固定值）
- `j=2`：`T[2]=b`，`T[next[2]]=T[1]=a`，b != a，`nextval[2] = next[2] = 1`
- `j=3`：`T[3]=a`，`T[next[3]]=T[1]=a`，a == a，`nextval[3] = nextval[1] = 0`
- `j=4`：`T[4]=b`，`T[next[4]]=T[2]=b`，b == b，`nextval[4] = nextval[2] = 1`
- `j=5`：`T[5]=a`，`T[next[5]]=T[3]=a`，a == a，`nextval[5] = nextval[3] = 0`
- `j=6`：`T[6]=a`，`T[next[6]]=T[4]=b`，a != b，`nextval[6] = next[6] = 4`
- `j=7`：`T[7]=a`，`T[next[7]]=T[2]=b`，a != b，`nextval[7] = next[7] = 2`
- `j=8`：`T[8]=b`，`T[next[8]]=T[2]=b`，b == b，`nextval[8] = nextval[2] = 1`

## 三、考点总结

1. **BF 算法的时间复杂度**：最坏 O(mn)，平均 O(mn)
2. **KMP 算法的时间复杂度**：O(m + n)，是模式匹配的重要优化
3. **next 数组的求解**是必考内容，需要掌握手动求解方法
4. **nextval 数组**是 next 数组的优化版本，也是常考点
5. **KMP 匹配过程**：主串指针 i 不回退是核心思想
6. 理解 next 数组的含义：最长相等前后缀长度 + 1
7. 注意 next 数组的下标从 1 开始（408 考研约定）
