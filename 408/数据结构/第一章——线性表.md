# 第一章——线性表

## 一、线性表的定义与基本操作

### 1.1 线性表的定义

线性表是具有**相同特性**的数据元素的一个**有限序列**。线性表中元素的个数 n（n >= 0）称为线性表的**长度**，n = 0 时称为**空表**。

线性表的特点：
- 存在唯一的一个没有前驱的**第一个元素**
- 存在唯一的一个没有后继的**最后一个元素**
- 除第一个元素外，每个元素都有且仅有一个**直接前驱**
- 除最后一个元素外，每个元素都有且仅有一个**直接后继**

### 1.2 线性表的基本操作

| 操作名称 | 功能描述 |
|---------|---------|
| `InitList(&L)` | 初始化表，构造一个空的线性表 L |
| `Length(L)` | 返回线性表 L 的长度，即元素个数 |
| `LocateElem(L, e)` | 按值查找，返回元素 e 在表中的位序 |
| `GetElem(L, i)` | 按位查找，返回表中第 i 个元素的值 |
| `ListInsert(&L, i, e)` | 在表 L 中第 i 个位置插入元素 e |
| `ListDelete(&L, i, &e)` | 删除表 L 中第 i 个位置的元素，并用 e 返回其值 |
| `PrintList(L)` | 输出线性表 L 的所有元素值 |
| `Empty(L)` | 判断线性表 L 是否为空表 |
| `DestroyList(&L)` | 销毁线性表，释放内存空间 |

> **考点提示**：基本操作的接口定义是选择题常考点，需注意参数中 `&` 表示引用传递（C语言中为指针）。

## 二、线性表的顺序存储

### 2.1 顺序表的定义

顺序表是用一组**地址连续**的存储单元依次存储线性表中的数据元素，使得逻辑上相邻的两个元素在物理位置上也相邻。

顺序表的实现方式：
```c
#define MaxSize 100      // 定义最大长度
typedef struct {
    ElemType data[MaxSize]; // 存放数据元素
    int length;             // 当前长度
} SqList;                  // 顺序表的类型定义
```

也可以使用**动态分配**的方式：
```c
typedef struct {
    ElemType *data;     // 指示动态分配数组的指针
    int MaxSize;        // 数组的最大容量
    int length;         // 当前长度
} SeqList;

// 初始化
void InitList(SeqList *L) {
    L->data = (ElemType *)malloc(sizeof(ElemType) * MaxSize);
    L->length = 0;
    L->MaxSize = MaxSize;
}
```

### 2.2 顺序表上基本操作的实现

#### 插入操作 `ListInsert(&L, i, e)`

在第 i（1 <= i <= L.length + 1）个位置插入元素 e：

```c
bool ListInsert(SqList *L, int i, ElemType e) {
    if (i < 1 || i > L->length + 1) return false;  // 判断 i 是否合法
    if (L->length >= MaxSize) return false;          // 判断是否已满
    for (int j = L->length; j >= i; j--)
        L->data[j] = L->data[j - 1];                // 第 i 个及之后的元素后移
    L->data[i - 1] = e;                              // 放入新元素
    L->length++;                                     // 长度加 1
    return true;
}
```

**时间复杂度分析**：
- 最好情况：在表尾插入，不需要移动元素，时间复杂度为 **O(1)**
- 最坏情况：在表头插入，所有元素都要后移，时间复杂度为 **O(n)**
- **平均情况**：在第 i 个位置插入的概率为 $p_i = 1/(n+1)$，平均移动次数为：
$$E_{insert} = \sum_{i=1}^{n+1} (n-i+1) \times \frac{1}{n+1} = \frac{n}{2}$$
- **平均时间复杂度为 O(n)**

#### 删除操作 `ListDelete(&L, i, &e)`

删除第 i（1 <= i <= L.length）个位置的元素，用 e 返回：

```c
bool ListDelete(SqList *L, int i, ElemType *e) {
    if (i < 1 || i > L->length) return false;       // 判断 i 是否合法
    *e = L->data[i - 1];                              // 将要删除的元素赋值给 e
    for (int j = i; j < L->length; j++)
        L->data[j - 1] = L->data[j];                 // 第 i 个之后的元素前移
    L->length--;                                      // 长度减 1
    return true;
}
```

**时间复杂度分析**：
- 最好情况：删除表尾元素，不需要移动，**O(1)**
- 最坏情况：删除表头元素，所有元素都要前移，**O(n)**
- **平均时间复杂度为 O(n)**

#### 按值查找 `LocateElem(L, e)`

```c
int LocateElem(SqList L, ElemType e) {
    for (int i = 0; i < L.length; i++)
        if (L.data[i] == e) return i + 1;  // 返回位序
    return 0;  // 未找到
}
```

**时间复杂度分析**：
- 最好情况：第一个元素就是目标，**O(1)**
- 最坏情况：最后一个元素或不存在，**O(n)**
- **平均时间复杂度为 O(n)**

### 2.3 顺序表的特点

| 优点 | 缺点 |
|------|------|
| 支持随机访问，通过下标直接获取元素 O(1) | 插入和删除操作需要移动大量元素 O(n) |
| 存储密度高，每个节点只存储数据元素 | 需要预先分配连续的存储空间，容量受限 |

## 三、线性表的链式存储

### 3.1 单链表的定义

单链表通过一组**任意的**存储单元来存放线性表中的数据元素。每个节点除了存放数据元素外，还要存储指向后继节点的指针。

```c
typedef struct LNode {
    ElemType data;       // 数据域
    struct LNode *next;  // 指针域
} LNode, *LinkList;
```

- **头指针**：指向链表中第一个节点的指针
- **头节点**：在单链表第一个元素节点之前附加的一个节点，其数据域可以不存储信息（或存储表长等附加信息）
- **首元节点**：链表中第一个存储数据元素的节点

> **注意**：头节点不是必须的，但引入头节点可以方便对链表的操作（如插入、删除在第一个位置时不需要特殊处理）。

### 3.2 头插法建表

头插法将新节点始终插入到头节点的后面，即链表的**头部**。建表后链表中元素的顺序与输入顺序**相反**。

```c
LinkList List_HeadInsert(LinkList L) {
    LNode *s;
    int x;
    L = (LinkList)malloc(sizeof(LNode));  // 创建头节点
    L->next = NULL;
    scanf("%d", &x);                       // 读入数据
    while (x != 9999) {                    // 9999 为结束标志
        s = (LNode *)malloc(sizeof(LNode));
        s->data = x;
        s->next = L->next;                 // 新节点的 next 指向原来的第一个节点
        L->next = s;                       // 头节点的 next 指向新节点
        scanf("%d", &x);
    }
    return L;
}
```

**时间复杂度：O(n)**

**示例**：输入序列 1, 2, 3, 4，头插法建表结果：
```
头节点 → 4 → 3 → 2 → 1 → NULL
```

### 3.3 尾插法建表

尾插法将新节点始终插入到链表的**尾部**，需要维护一个尾指针。建表后链表中元素的顺序与输入顺序**相同**。

```c
LinkList List_TailInsert(LinkList L) {
    int x;
    L = (LinkList)malloc(sizeof(LNode));
    LNode *s, *r = L;  // r 为尾指针
    L->next = NULL;
    scanf("%d", &x);
    while (x != 9999) {
        s = (LNode *)malloc(sizeof(LNode));
        s->data = x;
        r->next = s;    // 尾节点的 next 指向新节点
        r = s;           // 更新尾指针
        scanf("%d", &x);
    }
    r->next = NULL;      // 尾节点置空
    return L;
}
```

**时间复杂度：O(n)**

**示例**：输入序列 1, 2, 3, 4，尾插法建表结果：
```
头节点 → 1 → 2 → 3 → 4 → NULL
```

### 3.4 按序号查找 `GetElem(L, i)`

```c
LNode *GetElem(LinkList L, int i) {
    if (i < 0) return NULL;
    LNode *p = L;  // p 指向头节点，第 0 个节点
    int j = 0;
    while (p != NULL && j < i) {
        p = p->next;
        j++;
    }
    return p;  // 返回第 i 个节点（头节点为第 0 个）
}
```

**时间复杂度：O(n)**

### 3.5 按值查找 `LocateElem(L, e)`

```c
LNode *LocateElem(LinkList L, ElemType e) {
    LNode *p = L->next;  // 从首元节点开始
    while (p != NULL && p->data != e)
        p = p->next;
    return p;  // 找到返回节点指针，否则返回 NULL
}
```

**时间复杂度：O(n)**

### 3.6 插入操作

在节点 p 之后插入新节点 s：
```c
s->next = p->next;  // 新节点的 next 指向 p 的后继
p->next = s;         // p 的 next 指向新节点
```

> **注意**：这两步**不能颠倒**！如果先执行 `p->next = s`，则 p 原来的后继就丢失了。

**时间复杂度**：
- 找到插入位置的前驱节点：O(n)
- 执行插入操作本身：O(1)
- **总体：O(n)**（主要时间花在查找上）

### 3.7 删除操作

删除节点 p 的后继节点 q：
```c
q = p->next;       // q 指向要删除的节点
p->next = q->next; // p 的 next 跳过 q
free(q);           // 释放 q 的空间
```

> **注意**：如果要删除的是指定节点（已知其指针），可以通过将后继节点的值复制到当前节点，然后删除后继节点来实现 O(1) 删除（前提是该节点不是尾节点）。

**时间复杂度**：与插入类似，总体 **O(n)**

### 3.8 双链表

双链表每个节点有两个指针域：`prior`（前驱）和 `next`（后继）。

```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;
} DNode, *DLinkList;
```

**双链表的插入**（在节点 p 之后插入 s）：
```c
s->next = p->next;      // ①
p->next->prior = s;     // ②
s->prior = p;           // ③
p->next = s;            // ④
```
> **注意**：操作顺序为 ①→②→④→③ 或 ①→③→④→②，但 ② 必须在 ④ 之前（否则 p->next 已经改变）。

**双链表的删除**（删除节点 p 的后继 q）：
```c
p->next = q->next;       // ①
q->next->prior = p;      // ②
free(q);                  // ③
```

### 3.9 循环链表

#### 循环单链表

- 最后一个节点的 `next` 指向**头节点**（或首元节点）
- 判断空表条件：`L->next == L`（带头节点时）
- 判断是否到达表尾：`p->next == L`

#### 循环双链表

- 头节点的 `prior` 指向最后一个节点，最后一个节点的 `next` 指向头节点
- 判断空表条件：`L->next == L && L->prior == L`

> **考点**：循环链表可以从任意节点出发遍历整个链表。

### 3.10 静态链表

静态链表用**数组**来描述链表，用数组下标代替指针。

```c
#define MaxSize 100
typedef struct {
    ElemType data;    // 数据域
    int next;         // 下一个元素的数组下标（游标）
} SLinkList[MaxSize];
```

- 下标为 0 的元素通常作为**头节点**（或空闲链表的头节点）
- `next == -1` 表示到达链表末尾
- 不需要像动态链表那样频繁申请/释放内存，但需要预先分配最大空间

### 3.11 头节点与尾节点的作用

**头节点与尾节点对比**：

| 维度 | 头节点 | 尾节点 |
|------|--------|--------|
| 性质 | 附加的哑节点，不存有效元素，可选 | 真实元素节点（最后一个元素），有元素则必有 |
| next 指向 | 指向首元节点 | 普通单链表置 NULL；循环链表指向头节点（或首元节点）成环 |
| 主要价值 | 统一插入/删除/判空的边界处理 | 结束标志/闭合环路，配合尾指针实现头尾 O(1) 双定位 |

**头节点的两个作用**：

1. **统一空表与非空表的表示**：无论链表是否为空，头指针始终非空，判空统一为 `L->next == NULL`
2. **统一插入/删除的边界处理**：在第一个位置插入/删除与其他位置操作方式一致，无需对头指针单独分支

没有头节点时：对第一个元素节点的插入、删除要直接修改头指针本身，必须单独写分支；空表时头指针为 NULL，操作前需特判。

**尾节点的作用**：

- **单链表**：尾节点 `next == NULL` 是遍历终止标志；若另设尾指针，表尾定位 O(1)，但找表头需顺着 next 走到尽头
- **循环链表**：尾节点 `next` 指回头节点闭合环路；设尾指针 `tail` 时 `tail->next` 即头节点，头尾均可 O(1) 定位，两个循环链表拼接也只需 O(1)
- **循环双链表**：头节点 `prior` 指向尾节点、尾节点 `next` 指向头节点，结构对称，恒有 `p->next->prior == p == p->prior->next`

没有尾节点时：非循环链表遍历无终止标志；表尾追加需 O(n) 从头找尾；循环链表失去成环的连接点。

> **考点**："带头节点 vs 不带头节点"影响的是第一个位置的插入删除与判空，对查找、求表长影响不大；循环链表大题（拼接、约瑟夫环）几乎都依赖尾节点的环状连接，且优先用尾指针表示。

## 四、顺序表与链表的对比

| 对比项 | 顺序表 | 链表（单链表） |
|--------|--------|---------------|
| **存储方式** | 一段连续的存储空间 | 任意存储单元，通过指针链接 |
| **随机访问** | 支持，O(1) | 不支持，O(n) |
| **按值查找** | O(n) | O(n) |
| **插入操作** | O(n)，需要移动元素 | O(1)（找到位置后），不需要移动元素 |
| **删除操作** | O(n)，需要移动元素 | O(1)（找到位置后），不需要移动元素 |
| **空间分配** | 预先分配，可能造成空间浪费或溢出 | 动态分配，灵活但每个节点需要额外指针空间 |
| **存储密度** | 高（= 1） | 低（< 1，需要存储指针） |
| **适用场景** | 元素数量变化不大、频繁查找、很少插入删除 | 元素数量变化大、频繁插入删除、不知道表长上限 |

### 选择建议

- **选顺序表**：表长可预知、主要操作是查找、很少做插入删除
- **选链表**：表长不可预知、频繁做插入删除、需要动态增长

---

## 五、考点总结

1. **顺序表 vs 链表的选择**是高频选择题考点
2. **头插法 vs 尾插法**：注意头插法建表后元素顺序反转
3. **单链表的插入删除**：注意指针操作顺序，不能断链
4. **双链表的操作**：注意 prior 和 next 两个方向的指针都要维护
5. **时间复杂度**：顺序表随机访问 O(1)，链表不行；链表插入删除本身 O(1)，但查找前驱 O(n)
6. **静态链表**：了解游标的概念，适合不支持指针的语言
7. **头节点与尾节点**：头节点统一首位置插入删除与判空；循环链表尾节点成环，配尾指针可 O(1) 双定位头尾
