# 第四章——树与二叉树

## 一、树的基本概念

### 1.1 树的定义

树是 n（n >= 0）个节点的有限集合。当 n = 0 时称为空树。任意一棵非空树满足：
1. 有且仅有一个特定的称为**根**（Root）的节点
2. 当 n > 1 时，其余节点可分为 m（m > 0）个互不相交的有限集合，每个集合本身又是一棵树，称为根的**子树**

### 1.2 基本术语

| 术语 | 定义 |
|------|------|
| **节点的度** | 节点拥有的子树数 |
| **树的度** | 树中各节点度的最大值 |
| **叶子节点（终端节点）** | 度为 0 的节点 |
| **分支节点（非终端节点）** | 度不为 0 的节点 |
| **孩子节点** | 节点的子树的根
| **父节点（双亲）** | 上层节点
| **兄弟节点** | 同一父节点的子节点
| **节点的层次** | 从根开始定义，根为第 1 层（有些教材从 0 开始）
| **树的深度（高度）** | 树中节点的最大层次
| **路径** | 从节点 n1 到 nk 的节点序列，相邻节点间有边
| **路径长度** | 路径上经过的边数
| **祖先** | 从根到该节点路径上的所有节点
| **子孙** | 以某节点为根的子树中的所有节点 |

### 1.3 树的数量关系与计算公式

#### 1.3.1 两条基石公式

树的所有数量关系都源于一个事实：每条边恰好连接一个孩子，所以 **n 个节点的树恰有 n − 1 条边**。

- **边数公式**：$E = n - 1$
- **度数之和公式**：$\sum \deg = 0 \cdot n_0 + 1 \cdot n_1 + 2 \cdot n_2 + \dots + k \cdot n_k = n - 1$

> **度数之和 = 边数** 的原因：每个孩子恰给它的父节点贡献 1 度，n − 1 个孩子贡献 n − 1 度。

#### 1.3.2 叶子节点数公式（一般树）

设 $n_i$ 为度为 i 的节点数，树的最大度为 k。把 $n = n_0 + n_1 + \dots + n_k$ 代入度数之和公式：

$$0 \cdot n_0 + 1 \cdot n_1 + 2 \cdot n_2 + \dots + k \cdot n_k = (n_0 + n_1 + \dots + n_k) - 1$$

整理得**叶子数公式**：

$$n_0 = 1 + n_2 + 2n_3 + 3n_4 + \dots + (k-1) \cdot n_k$$

> **注意**：$n_1$ 不出现在公式中——度为 1 的节点"自吸收"（它有一个孩子也有一个父），不影响叶子数。

**示例**：一棵树中度为 2 的节点有 1 个，度为 3 的节点有 1 个，则 $n_0 = 1 + 1 + 2 \times 1 = 4$。

#### 1.3.3 树的度

**树的度** = 树中各节点度的最大值，即 $\max\{\deg(v) \mid v \in T\}$。

计算方法：遍历所有节点的度，取最大值。若某节点有 k 个孩子，则它的度为 k；所有节点中度最大的那个值就是树的度。

#### 1.3.4 树的高度（深度）

**树的高度** = 树中节点的最大层次。

> **约定**：本文（及国内多数教材如严蔚敏）取根在第 1 层，树高 = 最大层数。若改用"边数计高"（根高为 0），则所有高度/深度值减 1，但叶子数、度数之和等节点计数公式不受影响。

#### 1.3.5 m 叉树通用公式

| 对象 | 公式 |
|------|------|
| 第 i 层最多节点数 | $m^{i-1}$（根在第 1 层） |
| 深度为 k 的 m 叉树最多节点数 | $\dfrac{m^k - 1}{m - 1}$ |
| n 个节点的 m 叉树最小深度 | $\lceil \log_m(n(m-1) + 1) \rceil$ |

#### 1.3.6 二叉树与完全二叉树公式汇总

二叉树是 m = 2 的特例，叶子公式简化为 $n_0 = n_2 + 1$（见 2.2 性质 1）。

| 对象 | 公式 |
|------|------|
| 第 i 层最多节点数 | $2^{i-1}$（根在第 1 层） |
| 深度为 k 的二叉树最多节点 | $2^k - 1$ |
| 叶子数（任意二叉树） | $n_0 = n_2 + 1$ |
| 完全二叉树深度（n 个节点） | $\lfloor \log_2 n \rfloor + 1$ 或 $\lceil \log_2(n+1) \rceil$ |
| 完全二叉树叶子数 | $\lceil n/2 \rceil$ |
| 完全二叉树度为 1 的节点数 $n_1$ | 只能是 0 或 1 |

#### 1.3.7 数量关系速查表

以下示例对应一棵 7 节点的树（度为 3 的根 A，度为 2 的节点 B，度为 1 的节点 D，4 个叶子）：

| 量 | 值 | 计算依据 |
|------|------|------|
| 节点数 n | 7 | — |
| 边数 E | 6 | $E = n - 1$ |
| 度数之和 | 6 | $= 3 + 2 + 1 + 0 \times 4 = 6 = E$ |
| 树的度 | 3 | $\max\{3,2,1,0\}$ |
| 叶子数 $n_0$ | 4 | $1 + n_2 + 2n_3 = 1 + 1 + 2 = 4$ |
| 树高 | 3 | 最大层数 |

## 二、二叉树的定义与性质

### 2.1 二叉树的定义

二叉树是 n（n >= 0）个节点的有限集合：
1. 或者为空二叉树（n = 0）
2. 或者由一个根节点和两棵互不相交的左子树和右子树组成

> **重要**：二叉树是有序树，左子树和右子树是有区别的。二叉树不是度为 2 的有序树。

### 2.2 二叉树的五个重要性质

**性质 1**：非空二叉树上的叶子节点数等于度为 2 的节点数加 1。

$$n_0 = n_2 + 1$$

**证明**：设度为 0、1、2 的节点数分别为 $n_0, n_1, n_2$，总节点数 $n = n_0 + n_1 + n_2$。
从边的角度看，除根节点外每个节点有且仅有一条边指向它，总边数 = $n - 1$。
同时，度为 i 的节点有 i 条边引出，总边数 = $n_1 + 2n_2$。
因此：$n - 1 = n_1 + 2n_2$，即 $n_0 + n_1 + n_2 - 1 = n_1 + 2n_2$，得 $n_0 = n_2 + 1$。

**性质 2**：非空二叉树第 k 层最多有 $2^{k-1}$ 个节点（k >= 1）。

**性质 3**：高度为 h 的二叉树最多有 $2^h - 1$ 个节点。

**性质 4**：具有 n 个节点的完全二叉树的高度为 $\lceil \log_2(n+1) \rceil$ 或 $\lfloor \log_2 n \rfloor + 1$。

**性质 5**：对完全二叉树按层序编号（从 1 开始），对于编号为 i 的节点：
- 若 i = 1，则 i 是根节点，无双亲
- 若 i > 1，则其双亲编号为 $\lfloor i/2 \rfloor$
- 若 2i <= n，则左孩子编号为 2i，否则无左孩子
- 若 2i + 1 <= n，则右孩子编号为 2i + 1，否则无右孩子

### 2.3 满二叉树与完全二叉树

#### 满二叉树

一棵高度为 h，且含有 $2^h - 1$ 个节点的二叉树。每一层的节点数都达到最大值。

#### 完全二叉树

高度为 h、有 n 个节点的二叉树，当且仅当其每个节点都与高度为 h 的满二叉树中编号为 1 ~ n 的节点一一对应时，称为完全二叉树。

特点：
- 叶子节点只可能在最后两层
- 最多只有一个度为 1 的节点
- 若有度为 1 的节点，则只可能有左孩子

## 三、特殊二叉树

### 3.1 二叉排序树（BST）

二叉排序树（Binary Search Tree）或者是一棵空树，或者是满足以下性质的二叉树：
- 若左子树非空，则左子树上所有节点的值**均小于**根节点的值
- 若右子树非空，则右子树上所有节点的值**均大于**根节点的值
- 左、右子树也分别是二叉排序树

> **中序遍历**二叉排序树可以得到一个**递增有序序列**。

### 3.2 平衡二叉树（AVL）

平衡二叉树（AVL Tree）或者是一棵空树，或者是满足以下性质的二叉排序树：
- 左子树和右子树的**深度之差的绝对值不超过 1**
- 左、右子树也分别是平衡二叉树

节点的**平衡因子** = 左子树高度 - 右子树高度，平衡二叉树中所有节点的平衡因子只能是 -1、0、1。

## 四、二叉树的存储结构

### 4.1 顺序存储

用一组地址连续的存储单元自上而下、自左至右存储完全二叉树上的节点元素。

```c
#define MaxSize 100
typedef struct {
    ElemType data[MaxSize];  // 数组下标从 1 开始
    int nodeNum;
} SqBiTree;
```

> **适用场景**：仅适用于完全二叉树。对于一般二叉树，会造成大量空间浪费。

### 4.2 链式存储

```c
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;  // 左右孩子指针
} BiTNode, *BiTree;
```

在含有 n 个节点的二叉链表中，有 n + 1 个空指针域（利用性质 1 可证：2n 个指针域，n - 1 条边，空指针 = 2n - (n - 1) = n + 1）。

## 五、二叉树的遍历

### 5.1 先序遍历（Preorder）

访问顺序：**根 → 左 → 右**

```c
void PreOrder(BiTree T) {
    if (T != NULL) {
        visit(T);                  // 访问根节点
        PreOrder(T->lchild);       // 递归遍历左子树
        PreOrder(T->rchild);       // 递归遍历右子树
    }
}
```

### 5.2 中序遍历（Inorder）

访问顺序：**左 → 根 → 右**

```c
void InOrder(BiTree T) {
    if (T != NULL) {
        InOrder(T->lchild);        // 递归遍历左子树
        visit(T);                  // 访问根节点
        InOrder(T->rchild);       // 递归遍历右子树
    }
}
```

### 5.3 后序遍历（Postorder）

访问顺序：**左 → 右 → 根**

```c
void PostOrder(BiTree T) {
    if (T != NULL) {
        PostOrder(T->lchild);      // 递归遍历左子树
        PostOrder(T->rchild);      // 递归遍历右子树
        visit(T);                  // 访问根节点
    }
}
```

### 5.4 层序遍历（Level Order）

借助**队列**实现，按层次从上到下、从左到右访问。

```c
void LevelOrder(BiTree T) {
    Queue Q;
    InitQueue(&Q);
    if (T != NULL) EnQueue(&Q, T);
    while (!QueueEmpty(Q)) {
        BiTree p;
        DeQueue(&Q, &p);
        visit(p);
        if (p->lchild != NULL) EnQueue(&Q, p->lchild);
        if (p->rchild != NULL) EnQueue(&Q, p->rchild);
    }
}
```

### 5.5 非递归遍历

#### 先序遍历非递归

```c
void PreOrderNonRecur(BiTree T) {
    SqStack S;
    InitStack(&S);
    BiTree p = T;
    while (p != NULL || !StackEmpty(S)) {
        if (p != NULL) {
            visit(p);          // 先访问
            Push(&S, p);       // 再入栈
            p = p->lchild;     // 走到最左
        } else {
            Pop(&S, &p);       // 出栈
            p = p->rchild;     // 转向右子树
        }
    }
}
```

#### 中序遍历非递归

```c
void InOrderNonRecur(BiTree T) {
    SqStack S;
    InitStack(&S);
    BiTree p = T;
    while (p != NULL || !StackEmpty(S)) {
        if (p != NULL) {
            Push(&S, p);       // 入栈，不访问
            p = p->lchild;     // 走到最左
        } else {
            Pop(&S, &p);       // 出栈
            visit(p);          // 访问
            p = p->rchild;     // 转向右子树
        }
    }
}
```

#### 后序遍历非递归

后序遍历非递归需要标记节点是否已经访问过右子树：

```c
void PostOrderNonRecur(BiTree T) {
    SqStack S;
    InitStack(&S);
    BiTree p = T, r = NULL;
    while (p != NULL || !StackEmpty(S)) {
        if (p != NULL) {
            Push(&S, p);
            p = p->lchild;
        } else {
            GetTop(S, &p);     // 读栈顶但不弹出
            if (p->rchild != NULL && p->rchild != r) {
                p = p->rchild; // 右子树未访问过
            } else {
                Pop(&S, &p);
                visit(p);      // 访问
                r = p;         // 记录最近访问的节点
                p = NULL;      // 防止重复入栈
            }
        }
    }
}
```

### 5.6 遍历序列的确定

> **重要考点**：已知先序和中序序列可以唯一确定二叉树；已知后序和中序序列可以唯一确定二叉树；已知先序和后序序列**不能**唯一确定二叉树（无法区分左右子树）。

**示例**：先序序列 `ABDECFG`，中序序列 `DBEAFCG`

1. 先序第一个 A 是根
2. 中序中 A 左边 `DBE` 是左子树，右边 `FCG` 是右子树
3. 左子树先序 `BDE`，中序 `DBE`：B 是根，D 是 B 的左孩子，E 是 B 的右孩子
4. 右子树先序 `CFG`，中序 `FCG`：C 是根，F 是 C 的左孩子，G 是 C 的右孩子

构建的二叉树：
```
        A
       / \
      B   C
     / \ / \
    D  E F  G
```

## 六、线索二叉树

### 6.1 线索二叉树的概念

利用二叉链表中的 n + 1 个空指针域，存放指向该节点在某种遍历序列中的**前驱**和**后继**的指针，这种附加的指针称为**线索**。

加上线索的二叉树称为**线索二叉树**。

### 6.2 线索二叉树的存储结构

```c
typedef struct ThreadNode {
    ElemType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;  // ltag = 0 表示 lchild 指向左孩子，= 1 表示指向前驱
                      // rtag = 0 表示 rchild 指向右孩子，= 1 表示指向后继
} ThreadNode, *ThreadTree;
```

### 6.3 中序线索二叉树

中序遍历建立线索的过程：

```c
void InThread(ThreadTree p, ThreadTree pre) {
    if (p != NULL) {
        InThread(p->lchild, pre);  // 递归左子树
        if (p->lchild == NULL) {   // 左子树为空，建立前驱线索
            p->lchild = pre;
            p->ltag = 1;
        }
        if (pre != NULL && pre->rchild == NULL) {  // 前驱的右子树为空，建立后继线索
            pre->rchild = p;
            pre->rtag = 1;
        }
        pre = p;  // 更新 pre
        InThread(p->rchild, pre);  // 递归右子树
    }
}
```

> **考点**：线索二叉树中找前驱后继的方法，以及中序线索二叉树不需要栈就能实现中序遍历。

## 七、哈夫曼树与哈夫曼编码

### 7.1 哈夫曼树（最优二叉树）

**带权路径长度（WPL）**：树中所有叶子节点的带权路径长度之和。

$$WPL = \sum_{i=1}^{n} w_i \times l_i$$

其中 $w_i$ 是第 i 个叶子节点的权值，$l_i$ 是该叶子到根的路径长度。

**哈夫曼树**：在含有 n 个带权叶子节点的二叉树中，WPL 最小的二叉树。

### 7.2 哈夫曼树的构造

构造算法（哈夫曼算法）：
1. 将 n 个权值构造成 n 棵只有根节点的二叉树，构成森林 F
2. 在 F 中选取两棵**根节点权值最小**的树作为左右子树，构造一棵新二叉树，新根节点的权值 = 左右子树根节点权值之和
3. 在 F 中删除这两棵树，将新树加入 F
4. 重复步骤 2-3，直到 F 中只剩一棵树

**示例**：权值集合 {2, 3, 4, 5, 7}

| 步骤 | 森林 | 选取 | 新树 |
|------|------|------|------|
| 初始 | {2, 3, 4, 5, 7} | - | - |
| 1 | {4, 5, 7, (5)} | 2, 3 | 2+3=5 |
| 2 | {5, 7, (5), (9)} | 4, 5 | 4+5=9 |
| 3 | {7, (9), (10)} | 5, 5 | 5+5=10 |
| 4 | {(9), (10), (17)} | 7, 10 | 7+10=17 |
| 5 | {(17), (26)} | 9, 17 | 9+17=26 |

最终哈夫曼树：
```
         26
        /  \
       9    17
      / \   / \
     4   5 7  10
         /   / \
        2   3  5
            (注：此处的 5 是原集合中的 5)
```

> **注意**：哈夫曼树中不存在度为 1 的节点。含有 n 个叶子节点的哈夫曼树共有 2n - 1 个节点。

### 7.3 WPL 计算示例

以上述哈夫曼树为例：

| 叶子节点 | 权值 w | 路径长度 l | w * l |
|---------|--------|-----------|-------|
| 2 | 2 | 3 | 6 |
| 3 | 3 | 3 | 9 |
| 4 | 4 | 2 | 8 |
| 5 | 5 | 2 | 10 |
| 7 | 7 | 2 | 14 |

$$WPL = 6 + 9 + 8 + 10 + 14 = 47$$

### 7.4 哈夫曼编码

哈夫曼编码是**前缀编码**（任何一个字符的编码都不是另一个字符编码的前缀），用于数据压缩。

编码方法：从根到叶子，左分支标 0，右分支标 1。

以上述哈夫曼树为例：
- 2: `110`
- 3: `111`
- 4: `00`
- 5: `01`
- 7: `10`

> **考点**：哈夫曼编码不一定是唯一的（因为左右子树的分配可以互换），但 WPL 是唯一的。

## 八、树与森林的转换

### 8.1 树转换为二叉树

规则：**左孩子右兄弟**表示法
1. 兄弟节点之间加连线
2. 对每个节点，只保留与第一个孩子的连线，去掉与其他孩子的连线
3. 以根节点为轴心，顺时针旋转 45 度

转换后的二叉树特点：根节点没有右子树

### 8.2 森林转换为二叉树

1. 将每棵树分别转换为二叉树
2. 将第 2 棵二叉树作为第 1 棵二叉树根节点的右子树，第 3 棵作为第 2 棵根节点的右子树，以此类推

### 8.3 二叉树还原为森林

规则：若二叉树根节点有右孩子，则将右子树分离出来作为第二棵树，递归处理。

### 8.4 树和森林的遍历

| 结构 | 先序遍历 | 后序遍历 |
|------|---------|---------|
| 树 | 先访问根，再依次先序遍历各子树 | 先依次后序遍历各子树，再访问根 |
| 森林 | 先序遍历第一棵树，再先序遍历剩余森林 | 后序遍历第一棵树，再后序遍历剩余森林 |

> **对应关系**：树的先序遍历 = 对应二叉树的先序遍历；树的后序遍历 = 对应二叉树的中序遍历。

## 九、考点总结

1. **二叉树的五个性质**是基础，特别是 $n_0 = n_2 + 1$
2. **完全二叉树的性质**：性质 4 和性质 5 是高频考点
